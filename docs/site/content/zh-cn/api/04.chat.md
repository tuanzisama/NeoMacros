# chat

neo.chat 门面：聊天输出服务。say 发往所连服务器；log 与 actionbar 仅本地渲染。

## Examples

发送到服务器，或只在本地渲染：

```js
const { chat } = neo;

chat.say("所有人可见");        // 以玩家身份发送
chat.log("只有自己能看到");    // 本地聊天行
chat.actionbar("快捷栏上方");  // 临时叠加行
```
