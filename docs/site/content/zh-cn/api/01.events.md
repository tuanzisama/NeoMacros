# events

neo.events 门面：事件总线上的 EventEmitter 风格订阅。模块装载期创建的订阅归属该模块，模块卸载时自动退订。

Category: 核心 · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.events` and `@neomacros/events`

## Methods

### `emit(name: string, payload: unknown)`

触发一个自定义事件；载荷须为普通对象（或 undefined），走异步通道。名称须先注册；载荷键不得占用 BaseEvent 保留字（type、timestamp、cancellable）。

### `off(handleOrName: unknown)`

按句柄或事件名注销订阅。

**Parameters**

- `handleOrName` `unknown`: 

Since: 0.1.0 · MC: * · Loader: *

### `on(name: string, handler: Consumer)`

异步订阅事件；处理器在脚本上下文的事件循环线程上执行。

**Parameters**

- `name` `string`: 事件名，支持 domain:* 与 * 通配
- `handler` `Consumer`: 事件载荷处理器

**Returns** `unknown` — 传回 的不透明订阅句柄

Since: 0.1.0 · MC: * · Loader: *

### `onSync(name: string, handler: Predicate)`

在分发线程上同步订阅；仅可取消事件可用。回调返回 truthy 即取消该事件。

**Parameters**

- `name` `string`: 事件名（仅可取消事件）
- `handler` `Predicate`: 判定回调：返回 truthy 取消事件；须短小

Since: 0.1.0 · MC: * · Loader: *

## Examples

异步订阅、一次性等待与可取消的同步处理器：

```js
const { events, chat } = neo;

const sub = events.on("player:damage", (p) => chat.log(`-${p.amount}`));
events.once("player:spawn", () => chat.log("首次生成"));
const sound = await events.waitFor("world:sound");

// 可取消事件必须用 onSync；返回 truthy 取消动作。
events.onSync("player:attackBlock", (p) => p.y < -60);
```
