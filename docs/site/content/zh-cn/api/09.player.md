# player

neo.player 门面：本地玩家与当前打开的容器屏幕。self 是经玩家端口回读当前状态的活句柄；不在世界内时回读为 undefined。

Category: 世界 · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.player` and `@neomacros/player`

**Classes**

[`Inventory`](classes/inventory) · [`LocalPlayer`](classes/localplayer) · [`Player`](classes/player) · [`PlayerInventory`](classes/playerinventory)

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `opened` | [Inventory](classes/inventory) | 当前打开的容器屏幕句柄；无屏幕时为 undefined。 (read-only) |
| `self` | [LocalPlayer](classes/localplayer) | 本地玩家句柄；不在世界内时为 undefined。 (read-only) |


## Examples

本地玩家是实时句柄；需要稳定副本时取一份快照：

```js
const { player, chat } = neo;

const p = player.self;
if (p?.valid) {
    chat.log(`${p.name} 位于 ${p.x}, ${p.y}, ${p.z}，血量 ${p.health}`);
    const snapshot = p.snapshot(); // 时间点快照
}
```
