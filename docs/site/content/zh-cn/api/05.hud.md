# hud

neo.hud 门面：叠加在原版 HUD 之上的文本层。文本条目跨帧保留，直到移除或模块卸载。

Category: 界面 · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.hud` and `@neomacros/hud`

## Methods

### `addText(id: string, text: string, x: number, y: number, color: number)`

在 HUD 覆盖层上添加一条持久文本。

**Parameters**

- `id` `string`: stable text identifier (remove via )
- `text` `string`: the text content
- `x` `number`: screen x (pixels from left)
- `y` `number`: screen y (pixels from top)
- `color` `number`: ARGB color (e.g. 0xFFFFFFFF for white)

**Returns** `Promise<void>`

Since: 0.1.0 · MC: * · Loader: *

### `removeText(id: string)`

### `textIds()`

列出所有已注册的 HUD 文本标识。

**Returns** `Array<string>`

Since: 0.1.0 · MC: * · Loader: *


## Examples

HUD 上的持久文本条目，按 id 更新：

```js
const { hud } = neo;

await hud.addText("coords", "0 / 64 / 0", 8, 8, 0xFFFFFFFF);
const ids = await hud.textIds(); // ["coords"]
await hud.removeText("coords");
```
