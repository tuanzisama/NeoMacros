# net

neo.net 门面：fetch 语义的 HTTP 客户端。请求在专用 IO 线程池执行，需 net 能力授权；Promise 以活 Response 落定，其 body 读取器（text()、json()、bytes()）均为异步。

Category: 系统 · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.net` and `@neomacros/net`

## Methods

### `fetch(url: string, init: unknown)`

以 fetch 语义发起 HTTP 请求；init 携带 method/headers/body。

**Parameters**

- `url` `string`: 绝对 http(s) URL
- `init` `unknown`: 请求初始化对象（可省略）

**Returns** `Promise<Response>` — Promise，以 Response 落定

Since: 0.1.0 · MC: * · Loader: * · Permission: `net`

## Examples

向绝对 https 地址发起 HTTP 请求（需要 `net` 能力）：

```js
const { net } = neo;

const res = await net.get("https://api.example.com/status");
if (res.status === 200) {
    // res.body 是响应文本
}

await net.request("POST", "https://api.example.com/hook", '{"ok":true}', {
    "Content-Type": "application/json",
});
```
