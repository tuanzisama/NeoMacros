# storage

The neo.storage facade: persistent per-script key-value storage. Values must be JSON-serializable plain data (objects, arrays, strings, numbers, booleans); each script owns an isolated store keyed by its source file name, surviving reloads and game restarts.

Category: Core · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.storage` and `@neomacros/storage`

## Examples

Per-script JSON persistence that survives reloads and restarts:

```js
const { storage } = neo;

storage.put("visits", { count: 1, last: "2026-11-01" });
const visits = storage.get("visits");

storage.remove("visits"); // or storage.put("visits", null)
```
