# chat

The neo.chat facade: chat output services. Sending targets the connected server; log and actionbar render locally only.

Category: UI · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.chat` and `@neomacros/chat`

## Methods

### `actionbar(message: string)`

Renders the message on the action bar above the hotbar.

**Parameters**

- `message` `string`: 

Since: 0.1.0 · MC: * · Loader: *

### `log(message: string)`

Prints the message to the local chat HUD only.

**Parameters**

- `message` `string`: 

Since: 0.1.0 · MC: * · Loader: *

### `say(message: string)`

Sends the message to the connected server as if typed by the player.

**Parameters**

- `message` `string`: 

Since: 0.1.0 · MC: * · Loader: *


## Examples

Send to the server, or render locally only:

```js
const { chat } = neo;

chat.say("visible to everyone");     // sent as if typed by the player
chat.log("only you see this");       // local chat line
chat.actionbar("above the hotbar");  // temporary overlay line
```
