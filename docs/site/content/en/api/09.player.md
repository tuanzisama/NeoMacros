# player

The neo.player facade: the local player plus the currently open container screen. self is a live handle reading current state through the player port; outside a world it reads back as undefined.

Category: World · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.player` and `@neomacros/player`

**Classes**

[`Inventory`](classes/inventory) · [`LocalPlayer`](classes/localplayer) · [`Player`](classes/player) · [`PlayerInventory`](classes/playerinventory)

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `opened` | [Inventory](classes/inventory) | The currently open container screen as an Inventory handle, or undefined when no container screen is open. (read-only) |
| `self` | [LocalPlayer](classes/localplayer) | The local player handle, or undefined when not in a world. (read-only) |


## Examples

The local player is a live handle; take a snapshot for a stable copy:

```js
const { player, chat } = neo;

const p = player.self;
if (p?.valid) {
    chat.log(`${p.name} at ${p.x}, ${p.y}, ${p.z} with ${p.health} HP`);
    const snapshot = p.snapshot(); // point-in-time copy
}
```
