# render

The neo.render facade: world-space shape drawing on top of the vanilla gizmo pipeline. Shapes persist across frames until cleared or the module unloads; coordinates are world coordinates.

Category: UI · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.render` and `@neomacros/render`

## Examples

World-space overlays accumulate per named layer until cleared:

```js
const { render } = neo;

render.drawLine("path",
    { x: 0, y: 64, z: 0 }, { x: 10, y: 64, z: 10 }, 0xFF00FF00);
render.drawBox("zone",
    { x: 0, y: 64, z: 0 }, { x: 5, y: 70, z: 5 }, 0xFF0000FF);

render.clearLayer("path"); // drop just this layer's shapes
```
