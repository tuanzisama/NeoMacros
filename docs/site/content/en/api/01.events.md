# events

The neo.events facade: EventEmitter-style subscription over the event bus. Subscriptions created while a module is loading are attributed to that module and auto-unsubscribed when the module unloads.

Category: Core · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.events` and `@neomacros/events`

### `on(name: string, handler: Consumer)`

Subscribes asynchronously; the handler runs on the script context's event loop. Wildcard patterns (domain:*, *) are allowed.

**Parameters**

- `name` `string`: 事件名，支持 domain:* 与 * 通配
- `handler` `Consumer`: 事件载荷处理器

**Returns** `unknown` — an opaque subscription handle passed back to

Since: 0.1.0 · MC: * · Loader: *

### `onSync(name: string, handler: Predicate)`

Subscribes synchronously on the dispatch thread; only cancellable events accept sync subscriptions. The callback receives the payload and returns a truthy value to cancel the event (filter-style, like Array.filter). Sync callbacks must stay short; they block the dispatch thread.

**Parameters**

- `name` `string`: 事件名（仅可取消事件）
- `handler` `Predicate`: 判定回调：返回 truthy 取消事件；须短小

Since: 0.1.0 · MC: * · Loader: *

## Examples

Async subscriptions, one-shot waits, and cancellable sync handlers:

```js
const { events, chat } = neo;

const sub = events.on("player:damage", (p) => chat.log(`-${p.amount}`));
events.once("player:spawn", () => chat.log("first spawn"));
const sound = await events.waitFor("world:sound");

// Cancellable events require onSync; a truthy return cancels the action.
events.onSync("player:attackBlock", (p) => p.y < -60);
```
