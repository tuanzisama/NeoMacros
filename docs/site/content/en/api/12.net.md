# net

The neo.net facade: HTTP client with fetch semantics. Requests run on a dedicated IO executor and require the net capability; the promise settles with a live whose body readers (text(), json(), bytes()) are async.

Category: System · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.net` and `@neomacros/net`

## Methods

### `fetch(url: string, init: unknown)`

Performs an HTTP request with fetch semantics. The init object carries method (default GET), headers (map) and body (string).

**Parameters**

- `url` `string`: 绝对 http(s) URL
- `init` `unknown`: 请求初始化对象（可省略）

**Returns** `Promise<Response>`

Since: 0.1.0 · MC: * · Loader: * · Permission: `net`

## Examples

HTTP requests to absolute https URLs (requires the `net` capability):

```js
const { net } = neo;

const res = await net.get("https://api.example.com/status");
if (res.status === 200) {
    // res.body holds the response text
}

await net.request("POST", "https://api.example.com/hook", '{"ok":true}', {
    "Content-Type": "application/json",
});
```
