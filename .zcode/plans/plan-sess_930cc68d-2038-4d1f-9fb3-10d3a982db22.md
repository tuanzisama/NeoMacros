# GraalJS console API → SSE → 编辑器控制台

## Context

宏脚本目前没有任何调试输出通道:GraalJS session 只注入 `neo` 全局,`console` 不存在(内嵌模式内置 console 未配置)。目标:给每个脚本注入完整浏览器语义的 `console`,输出经 SSE 实时推送到编辑器新增的独立"控制台"面板,支持结构化富文本渲染(MC `Component`、Java Class/反射对象)、宏 ID/文件名/行号定位与点击跳转 Monaco、镜像 log4j、服务端环形缓冲回放、限流与序列化截断。

## 已确认的需求决策

独立"控制台"面板 / 结构化富文本渲染 / 完整浏览器语义(log/info/warn/error/debug/trace/dir/table/count/time/timeLog/timeEnd/group/groupEnd/clear/assert) / 镜像 log4j + 环形回放 / 点击跳转 Monaco / 限流+截断 / 面板支持按宏过滤、级别过滤、文本搜索、时间戳 / console 无条件可用(不进 meta.permissions)

## 数据契约(两端共同语言)

SSE 事件名 `console`;REST `GET /api/v1/console?after=seq` → `{entries, lastSeq}`。条目结构(Java record ↔ TS interface):

```
ConsoleEntry {
  seq: long, ts: epochMillis, macro: string,
  kind: 'log'|'trace'|'dir'|'table'|'count'|'time'|'timeEnd'|'group'|'groupEnd'|'clear'|'assert',
  level: 'log'|'info'|'warn'|'error'|'debug',
  file: string|null,      // 宏目录内相对 POSIX 路径,如 "index.js"
  line: int|null, col: int|null, depth: int,
  args: ConsoleNode[],    // 结构化参数树
  label: string|null, count: int|null, ms: double|null, stack: string|null
}

ConsoleNode 按 t 判别:
  {t:'str',v} {t:'num',v} {t:'bool',v} {t:'null'} {t:'undef'}
  {t:'obj', pre, props:[{k,v:Node}], n, tr}        // tr=truncated
  {t:'arr', pre, len, items:[Node], tr}
  {t:'fn', name}
  {t:'err', name, msg, stack}
  {t:'class', name}                                  // java.lang.Class
  {t:'comp', rich: ChatComponent}                    // MC Component 富文本(port 模型)
  {t:'host', cls, pre, props?:[{k,v:Node}]}          // 其余宿主对象
```

截断上限(引擎侧建节点时):字符串 2000 字符、obj 预览 140/属性 30、数组元素 100、深度 4、单次 emit 节点总数 400、stack 4000 字符。

## 后端(3 个模块)

### 1. core(版本无关)

- 新增 `core/console/ScriptConsole.java`(静态 hub,仿 `ScriptApiEnvironment` 模式):
  - `installDispatcher(Consumer<ScriptConsoleEvent>) / removeDispatcher`(CopyOnWriteArrayList 扇出)
  - `installComponentView(Function<Object, ChatComponent>)`(product 启动时注册;引擎遇到宿主对象先问它)
  - `record ScriptConsoleEvent(macro, kind, level, file, line, column, depth, args(List<Object> 节点), label, count, ms, stack, timestampMillis)`
- `ports` 模型 `ChatComponent` 增加可空 `Boolean obfuscated` 字段(现状只有 text/color/bold/italic/underlined/strikethrough/children;唯一调用点 `plain()` 同步更新)。

### 2. engine(GraalJsEngine)

- `GraalJsEngine.GraalJsSession`:
  - `openSession` 时在 js bindings 放入 `__neoConsoleEmit`(ProxyExecutable:`(level, kind, argsArray, extra, stack)`,读 extra 的 depth/label/count/ms 成员),随后随 GLUE 一起安装 console。
  - **GLUE 扩展**(现有 GLUE 字符串,源名保持 `neomacros-engine-glue`):JS 侧定义 `console`(`Object.defineProperty(globalThis,'console',{value,writable:false,configurable:false})`,覆盖任何内置)——所有方法只做薄包装:捕获 `new Error().stack`、维护 group 深度/timers Map/counters Map/assert 条件判断,然后调 `__neoConsoleEmit`。格式化全部在 Java 侧做。
  - 新增 `ConsoleValueFormatter`:递归把 `Value` → 节点 Map(上限见契约)。宿主对象分支顺序:`ScriptConsole.componentView(obj)` 非空 → `comp` 节点;`java.lang.Class` → `class`;`Throwable` → `err`;否则 `host`(类名 + toString 摘要 + 公有无参 getter 反射快照≤15 个,供面板展开)。
  - 新增 `ConsoleLocation`:解析 stack 字符串,跳过源名为 `neomacros-engine-glue` 的帧,取第一帧的 `source:line:col`;source 为文件 URI 时相对 `moduleRoot` 解析为相对 POSIX 路径,失败/虚拟模块 → file=null。
  - 新增每 session `RateLimiter`:令牌桶(突发 50,补充 25/s);丢弃时计数,恢复后补发一条合成 WARN(`console: N message(s) suppressed by rate limit`),每次丢弃周期只补一条。
- 无 dispatcher 时事件静默丢弃(console 仍存在,测试环境零开销)。

### 3. product(Fabric + web)

- `adapter/ComponentViews.java`(新):`Component → ChatComponent` 富文本转换,逐节点:`getStyle()` → color(TextColor 的 `getName()` 优先,否则 `#%06X`)+ bold/italic/underlined/strikethrough/obfuscated;文本用 `PlainTextContents.Literal` 字面量快路径,Translatable 等退化为 `getString()` 扁平节点(children 有内容时并入文本,不重复渲染 siblings)。该类编译在每个 stonecutter 节点下,若 26.x API 有差异用 `//? if` 块分叉。
- `NeoMacrosFabric`(bootstrap,web 装配块 `:238-258` 附近):
  - `ScriptConsole.installComponentView(ComponentViews::toChatView)`
  - **log4j 镜像 dispatcher**(不随 web 启停,常驻):logger `neomacros.console.<macro>`,格式 `[file:line] 扁平化参数`,error/warn/debug 映射对应 Level 其余 INFO。LogTap(前缀 `neomacros`)自动捕获 → 游戏日志文件与现有"日志"页也会出现纯文本行(预期行为)。
- `web/console/ConsoleRing.java`(新,克隆 `LogRing` 结构,Entry=完整 payload,capacity 1000)。
- `WebService.start()`(`:104-137` 模式):建 ring;`ScriptConsole.installDispatcher(evt -> ring.append(toEntry(evt)))`;`ring.addListener(entry -> events.broadcast("console", Jsons.stringify(entry)))`;`stop()` 反注册(保存引用以支持相等移除)。
- `v1/ApiV1.java`:照 `logs()`(`:350-361`)加 `@NmGet("/api/v1/console")`,参数 `@NmParam("after") Long after`,返回 `v1/ConsoleResponse(List<ConsoleEntry>, long lastSeq)`;`v1/ConsoleEntry.java` record。
- **刷新金样** `product/src/test/resources/web/openapi-golden.json`(测试断言提示了路径)。

## 编辑器(NeoMacros-editor)

- `src/types/api.ts`:`ConsoleNode`(可辨识联合)、`ConsoleEntry`、`ConsoleResponse`。
- `src/api/endpoints.ts`:`getConsole(after)`(query 自动签名,照 `getLogs` `:149-152`)。
- `src/api/sse.ts`:照 `onLog` 模式加 `consoleHandlers`/`onConsole` + `addEventListener('console', ...)`(`:121-125` 处)。
- `src/stores/console.ts`(新,仿 `logs.ts`):entries(上限 2000)、lastSeq、paused、macroFilter/levelFilter/search;`startConsole()` 初始 `getConsole(0)` 回放 + `sse.status` 变 'open' 时从 lastSeq 补洞(重连不丢);`bindConsoleSse()` 实时追加;`kind==='clear'` 时清空 entries(保留 seq);导出 `filteredEntries` computed。
- `src/components/devtools/ScriptConsoleTab.vue`(新):工具栏(宏下拉取自 macros store、级别下拉、搜索框、暂停、清屏),行 = 时间(HH:MM:SS)+ 级别色标 + 宏徽标 + 按 depth 缩进的消息区;location `file:line` 可点击。
- `src/components/devtools/ConsoleMessage.vue`(新):节点渲染 + 递归展开(obj/arr/err.stack/host.props 点击展开,浏览器 DevTools 风格);首个 string 参数含 `%s/%d/%i/%f/%j/%o/%c/%%` 时做替换(`%c` 仅消费不套样式);`comp` 节点渲染 MC 调色板映射的富文本 span(MC 16 色→CSS hex 表,hex 直通,bold/italic/underline/line-through);`table` 渲染简单 HTML 表(≤50 行/10 列,退化普通渲染);`trace`/`err` 折叠 stack。
- `src/components/devtools/registry.ts`:追加 `{ id: 'scriptconsole', label: '控制台', component: markRaw(ScriptConsoleTab) }`(原 'console' id 是"日志"页,不动)。
- **跳转机制**:`src/stores/editor.ts` 加 `revealTarget: {path, line, column, token}|null` + `revealInEditor(path, line, column)`(调 `openFile` 后置 target,token 自增保证重放);`MonacoPane.vue` watch 后 `revealPositionInCenter` + 选中该行。入口:entry 有 file/line 时 `${macro}/${file}` + line。
- `App.vue`:在 `bindLogSse()`(`:34-37`)旁加 `bindConsoleSse()`;`onOnline`/connection watch 处调 `startConsole()/stopConsole()`(镜像 `startLogs` 生命周期)。
- `dev-stub/server.mjs`:console 环形缓冲 + `/api/v1/console?after=` 路由(照 `:423-431`)+ `broadcast('console', …)`;每次 SSE 连接建立后 1s 推送一批演示条目(覆盖全部节点类型,含富文本/错误/表格),供本地开发验证。
