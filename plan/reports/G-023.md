## 3. D 类证据（9 签名，javap 1.21.6 与 26.3 各一次）

反查工具：`javap`（`-p` 时标明），1.21.6 用 loom named jar `minecraft-merged-1.21.6-loom.mappings…jar`，26.3 用 `minecraft-merged-deobf-26.3.jar`。

### 3.1 `EnderDragon.getBodyPart/getBodyParts` ×3 —— 龙体节不是可寻址实体

- `EnderDragon.getSubEntities()` 两节点 public，返回 `EnderDragonPart[]`（21：`world.entity.boss.EnderDragonPart`；26.3：`world.entity.boss.enderdragon.EnderDragonPart`），类 `extends Entity`、带 public `name` 字段。
- 但体节由龙在构造时自建为内部碰撞盒：`shouldBeSaved()` 返回 false、从不写入区块存档，也不进 `ClientLevel` 实体分片存储（`level.entitiesForRendering()` 不含它们）。
- NeoMacros 句柄 = UUID → `EntityApi.wrap` → `adapter().byUuid`（遍历 `entitiesForRendering`）。体节 UUID 永远解析不到，`getBodyPart(i)` 只会交出失效句柄（属性全 `undefined`）。
- 要落地必须新增"体节句柄"面（新 port 通道 + 新 guest 类），远超本批"小缺口"口径；13 §3.2 原判即 `getBodyPart/Parts→D 评估（Part 列表形态）`。
- **结论 D**：NeoMacros 不设成员；compat 需要时可经穿透层 `entity.raw.getSubEntities()[i]` 自取（12 号 §4.9 配方），不占脚本面。

### 3.2 `SpellcasterIllager.getCastedSpell()` —— 私有静态同步访问器

- `SpellcasterIllager.getCurrentSpell()` 为 `protected`；`DATA_SPELL_CASTING_ID`（`EntityDataAccessor<Byte>`）为 `private static final`（1.21.6 与 26.3 `javap -p` 同形）。
- 无任何公有路径读到当前施法 id；JsMacros 依赖其自有 mixin accessor（`MixinSpellcastingIllagerEntityHelper.getSpellKey()`）。
- 沿 13 §2.3 私有字段先例（`Vindicator.isJohnny`「无公有访问器（不挖 mixin）」、`MinecartFurnace.hasFuel`）标 **D**；既有 `castingSpell`（`isCastingSpell()`）已覆盖"是否在施法"的主用途。
- 升级路径（若协调方复议）：`@Accessor("DATA_SPELL_CASTING_ID")` 静态字段访问器 + `IllagerSpell` id→名映射，落点已就绪（`SpellcasterIllagerEntity` + `collectSpeciesState` 各一行）。

### 3.3 `Dolphin.getTreasurePos()` —— 服务端 AI 目的地，未同步

- `Dolphin.treasurePos` 字段 1.21.6 为包私有、26.3 为 private，且 **无对应 synched data**（`defineSynchedData` 不含它）——服务端寻宝 AI 的私有目的地。
- JsMacros 自身 javadoc 明写：*"its destination is not synchronized to clients"*（客户端读恒为 null）。
- **结论 D**（服务端-only），维持 13 §3.2 `treasurePos* ⚠` 的待评估状态并定案。

### 3.4 `Ocelot.isTrusting()` —— 私有 getter + 私有同步字段

- `Ocelot.isTrusting()` 1.21.6 包私有、26.3 private；`DATA_TRUSTING`（`EntityDataAccessor<Boolean>`）`private static final`（两节点 `javap -p`）。`setTrusting` 同为 private。
- 值本身是同步数据（客户端可观察），但唯一读取路径是私有静态访问器；JsMacros 依赖 `MixinOcelotEntity.invokeIsTrusting()`。
- 沿 §2.3 私有字段先例标 **D**（不挖 mixin）。升级路径同 §3.2（一个 `@Accessor` 字段访问器即可转 B）。

### 3.5 `FishingBobber.hasCaughtFish()` —— 私有 biting 字段

- `FishingHook.biting` 为 `private boolean`，`DATA_BITING` 为 `private static final EntityDataAccessor<Boolean>`；两节点均无公有 getter（`javap -p`）。
- JsMacros 用 `@Accessor("biting")` 读取。沿 §2.3 口径标 **D**；既有 `openWater` / `hookedEntity` / `angler` 已覆盖本批其余鱼钩成员。升级路径同 §3.2。

### 3.6 `Boat.isOnLand()/isInAir()` —— 状态枚举与判定链私有

- `AbstractBoat.status`（`private Status`）、`getStatus()`（private）、`checkInWater()`（private，按 AABB 列扫描流体）、`isUnderwater()`（private，返回 `Status`）全部不可达；`Status` 枚举（`IN_WATER/UNDER_WATER/UNDER_FLOWING_WATER/ON_LAND/IN_AIR`）本身 public 但取值源 private。
- 公开面只有 `isUnderWater()`（字节码 = 读 `status` 是否为两个水下态，已由既有 `underWater` 覆盖 = #62 A）与 `getGroundFriction()`（public）。`ON_LAND`/`IN_AIR` 依赖 `checkInWater()` 的私有流体扫描，无法无损复刻状态机。
- 13 §2.3 `BoatEntityHelper` 行已就 `getLocation` 状态枚举登记同类 D（「状态枚举无公有访问器」），本批两条派生谓词沿同口径。
- 升级路径（若复议）：`@Invoker("getStatus")` 一个 invoker 即可整组转 B（`status` 串 + 三态派生），两节点方法名已核实一致。

- 无参状态属性化：`isPowered()→powered`、`isProvoked()→provoked`、`isMoving()→moving`、`isCelebrating()→celebrating`、`isStanding()→standing`、`isBegging()→begging`、`getColor()→color`、`getStartPos()→startPos`、`getVariantId()→variantId`、`getSize()→size`、`getVarietyId()→varietyId`、`getBoatItem()→boatItem`、`getBlockState()→blockState`、`getHeldBlock()→heldBlock`。
- `has*` 查询保持方法（沿 `hasLeftHorn/hasPumpkin` 先例）：`hasChest()`；带参谓词保持方法：`isFood(itemId)`、`canBreedWith(other)`。
- 读同步：18 个新成员全为只读查询，无 Promise。
- 缺席 = `undefined`：`heldBlock`/`startPos`/`boatItem` 条目缺席或类型不符即返回 `null` → 引擎出口转 `undefined`（单测 `endermanHeldBlockReadsBackUndefinedWithoutState` 覆盖）。
- id 参数归一在 facade（`minecraft:` 前缀补全，同 `hasEffect`），端口拿到的已是全名（e2e 断言 `lastFoodId === 'minecraft:carrot'`）。

### 4.3 为什么 `isFood` 是 id 形态而不是对象形态

- 引擎 `HandleShape`（`GraalJsEngine`）按方法名 `putIfAbsent` 收成员——**同名重载只保留第一个**，`isFood(Item)`/`isFood(ItemStack)` 双载荷必然吞掉一个，因此 NeoMacros 只能给一个 `isFood`。
- 现有面同形态先例：`hasEffect(String id)`、`canBeAffected(String effectId)`、`canBeAffected` 端口注释即「namespace defaults to minecraft」。
- vanilla `Animal.isFood(ItemStack)` 各实现均为物品 id 判定（`stack.is(...)`），id 形态对原版动物与 JsMacros 两载荷等值；带组件差异的自定义动物不在覆盖面（已在成员 javadoc 注明"unknown ids answer false"，组件级差异留待按需）。

### 4.5 数据通路

`collectSpeciesState`（适配器、主线程）→ `speciesState(uuid)` 平面 map → facade `species*` 助手按 key 读取。本批新值类型：`BlockData`（`heldBlock`/`blockState` → facade 转 `types.BlockState(id, props)`）、`Pos3d`（`startPos` → facade 转 `types.BlockPos`，`BlockPos(double,double,double)` 自带向下取整）、`ItemStackData`（`boatItem` → facade 转 `types.ItemStack.of(...)`）、其余标量直通。
