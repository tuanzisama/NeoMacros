## 偏离与回写

1. **`getEntity` 由实施要点的 B 改判 D**（D 证据③）：离屏实体创建面落在实体泳道共享文件（`EntityPort/FabricEntityPort/EntityApi`），本任务禁改；如后续要该能力，需先开"预览实体"专项（创建+追踪+回收），不应塞进注册表任务。
2. **`getBlock`/`getBlockState` 收敛为同一默认状态面**（#8/#9）：沿 G-017 "Block 位置绑定" 与 G-027 `stack.block`→`BlockState` 既定口径；JsMacros BlockHelper 的类型级事实（name/tags/states…）仍经位置绑定 `block` 句柄与 `world().blockType` 可达，不另建类型级类。
3. **`getEnchantment` 的 `level` 形参用 `Object + @ApiType("number")` 而非 `Integer`**：引擎模块路径 `convertArgs→asJava` 不支持装箱标量（传入即抛 "cannot convert argument to java.lang.Integer"，实测），句柄路径 `convertArguments` 支持——**既有引擎缺口**（`ChatApi` 的 `@ApiOptional Integer fadeIn/stay/fadeOut`、`InputApi` 的 `@ApiOptional Boolean` 同受影响，凡从 guest 显式传值即触发）；本批不改引擎（非允许文件），建议后续引擎任务补 `asJava` 装箱分支。
4. **`Enchantment` 构造经一次性栈快照**（`enchantmentHandle`）：`Enchantment(String,int)` 为 `core/api/types` 包内构造、本任务不能改该包；经 `ItemStack.of(ItemStackData 含 EnchantmentData)` → `getEnchantments().get(0)` 得到同款句柄。若后续任务拥有 types 包，建议补 `Enchantment.of(id, level)` 公共工厂并回切。
5. **`parseIdentifier`/`getIdentifier` 返回 `string` 而非 `ResourceLocation`**（#40/#41）：原生标识对象属穿透层（Wiki "尽量别用"）；字符串形态与 `parseNameSpace` 对称、d.ts 干净。
6. **未知 id 一律 undefined（含回落 air 的场景）**：JsMacros `getItem/getBlock/getFluidState` 未知回落注册表默认（air/空流体），NeoMacros 按验收口径 `containsKey` 前置判空收敛为 undefined——与既有 `registryLookup` 口径一致。
7. **排序**：`getItems/getBlocks/statusEffects` 及连接侧 id 列表按 id 字典序（沿 `registryIds` 既有排序）；JsMacros 原序为注册序——顺序差异不影响集合值。

## 遗留（给下游）

1. **→ G-018B（状态句柄）**：`getStatusEffect/getStatusEffects` 已交付 `EntityApi.StatusEffectData(id, duration=0, amplifier=0, infinite=false)` 载体。G-018B 的 `StatusEffectHelper` 10 成员中 `getId→id`、`getTime→duration`、`isPermanent→infinite` 可直接 A 映射；`isAmbient/isIcon/hasVisible/isInstant/isBeneficial/isNeutral/isHarmful` 7 个需要 MobEffect 类型/实例事实，record 无法增补分量——G-018B 应在 ClientApi/ports/model 新设更宽的 DATA 面（或包装 record），并回切本两面的返回类型。
2. **→ G-004/005（compat 回桥）**：21 个 A 成员按上表 kind 串回桥（注意 `getStructureFeatureIds` 的 kind 是 `worldgen/structure_piece`、`getScreenHandlerIds` 是 `menu`）；`getFeatureIds` 桥 `registryIds('worldgen/feature')` 无门可用（节点门在适配器内）；4 个 D 成员维持壳桩并更新 reason 文案；`getIdentifier→parseIdentifier` 同值回桥。
3. **→ 引擎任务（非本泳道）**：`asJava` 缺装箱标量分支（偏离③），`ChatApi/InputApi` 受影响面一并修。
4. **→ 实体泳道（G-012/022/023 或专项）**：如需 JsMacros `getEntity` 的"创建未入世实体"语义，需预览实体面（创建+UUID 追踪+`byUuid` 可解析+回收），不在注册表任务内。
