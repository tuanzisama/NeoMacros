## 命名与形态决策

1. **句柄命名**：`OptionsHelper` → `Options`（13 号 §5.4 `client.options → Options HANDLE` 拍板），`VideoOptionsHelper` → `VideoOptions`，五个分组 → `SkinOptions/MusicOptions/ControlOptions/ChatOptions/AccessibilityOptions`；不沿用 `XxxHelper`。`client.options` 由旧的 `OptionsData` 快照升级为活句柄（属性读名 `fov/gamma/guiScale/renderDistance` 不变，兼容既有脚本与 compat shim 的 `neo.client.options.fov` 读法）。
2. **词表**：读属性、`OptionsData` 组件、`setOption(name, …)` 写名共用 **Mojang 选项词表**（`prioritizeChunkUpdates`/`ambientOcclusion`/`framerateLimit`/`enableVsync`/`bobView`/`attackIndicator`/`cloudStatus`/`particles`/`screenEffectScale`/`entityDistanceScaling`/`fovEffectScale`/`showAutosaveIndicator`），与既有 `client.option(name)`（T-515 白名单）同名；上表标注的「改名」即 JsMacros 名 → Mojang 名。无参状态一律属性（`getX/isX` → `x`），写动作一律 `setXxx` → `Promise`（`enableVsync(boolean)` 与属性 `enableVsync` 同名会撞 handleShape 键，故 setter 统一 `set` 前缀）。
3. **读写成对 + 回读校验**：所有写动作经 `ClientPort` 派发主线程落 `CompletableFuture`；facade 在写完成后重新读 `OptionsData` 比对（数值按 double 比、字符串忽略大小写、列表按集合相等），不一致 reject，错误信息带 `requested/stored`。三类动作无回读目标，按语义豁免并写进 javadoc：`saveOptions`（落盘）、`lockDifficulty/unlockDifficulty`（服务端生效，发包后 resolve；无连接 reject）、`sendSyncedOptions`（广播，同步 void）。
4. **缺席语义**：`options()` 空 → 全部属性 undefined；`difficultyLocked`（无世界）与 `fullscreenResolution`（未配置）为 null → undefined；`resourcePacks/enabledResourcePacks` 缺席时 `[]`。

## 与 JsMacros 的语义差异（有据）

1. **`removeServerResourcePack` 换实现**：JsMacros `MixinResourcePackManager` 在 `PackRepository.rebuildSelected` 上 `@Redirect Pack.isRequired()` 并匹配 pack id `"server"`；本环境 1.21.6/26.3 字节码确认 `rebuildSelected → Pack.isRequired()` 仍在（两节点逐字节一致），但服务器资源包 id 已是 `server/%08X/%s`（`DownloadedPackSource` 常量池），`equals("server")` 恒 false——其实在这些版本上是空操作。NeoMacros 改用 vanilla 公有 API `DownloadedPackSource.rejectServerPacks()/allowServerPacks()`（两节点 javap 均在），回读 = `ServerPackManager.packPromptStatus == DECLINED`（新增 2 个 `@Accessor` mixin：`DownloadedPackSourceAccessor.manager`、`ServerPackPromptAccessor.packPromptStatus`，字段名两节点一致）；状态变化时补 `reloadResourcePacks()`（与 JsMacros 一致）。
2. **越界写 reject 而非静默截断**：JsMacros 对 gamma/fov/fovEffectScale/biomeBlend 用 `MixinSimpleOption.forceSetValue` 绕过校验（本环境已无 `net.minecraft.client.SimpleOption` 类），其余用 `set()`——校验失败时值不变。NeoMacros 统一 `OptionInstance.set()`（javap：`ValueSet.validateValue` 失败 → 保留旧值），facade 回读不一致即 reject 并给出存储值；脚本可据错误信息改写合法值。
3. **`setEnabledResourcePacks` 校验口径**：按 `getSelectedIds()` 集合相等校验，必选包（如 `vanilla`）始终在内——传入列表应为 `options.enabledResourcePacks` 回读的全集；JsMacros 无校验。
4. **`setLanguage` 未知代码 reject**：JsMacros 未知代码静默跳过仍 reload；NeoMacros 直接 reject（回读校验也拦不住静默跳过之外的路径）。
5. **`setSize/setWidth/setHeight` 全屏时 reject**：`Window.setWindowed(int,int)` 字节码显示会顺带 `fullscreen=false` 并 `setMode()`，全屏下调用会意外退出全屏；JsMacros 的 GLFW 调用在全屏下行为未定义。窗口尺寸字段在 `setMode()` 内同步写入，回读即时成立。
6. **`sendSyncedOptions` 保持 `void`**：广播无回读目标，主线程同步派发（对齐 `grabMouse` 先例）；其余写全为 `Promise`。
7. **枚举写解析**：按当前值的枚举类型 `Enum.valueOf(name.toUpperCase)`，未知名 reject（JsMacros 保留原值继续 `set`，等价于回读失败，但错误信息更明确）；26.x `GraphicsPreset.CUSTOM` 可写 `custom`，1.21.6 `GraphicsStatus` 无该常量 → reject（版本差异见下表）。
8. **根面别名**：`getGamma/getGuiScale/getRenderDistance` 在根面重复暴露（委托 video），保持 0.5.0 前 `client.options` 快照的四字段读面不破（compat `getGameOptions()` shim 直读这四个属性）。
