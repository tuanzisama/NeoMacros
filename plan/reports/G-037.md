## 形态与失败语义（javadoc 已逐条写明）

1. **动作走 Promise**：`takePanorama` → `Promise<string>`（例程消息）。`writeSign` 保持**同步 boolean**——JsMacros 同签名，且与本文件 `close()` / `buildScreen` 的“同步豁免”同一口径（写编辑器缓冲是纯本地状态，无异步等待点）。
2. **失败语义**：
   - `writeSign`：无编辑器 → `false`（写不落）；主线程跳失败 → `IllegalStateException`（不把失败伪装成“没开”）。
   - `writeSignLine`：index 越界 → `IndexOutOfBoundsException`（**无编辑器也抛**，JsMacros 同款）；`message == null` → `NullPointerException`（该重载不接受 null 语义）。
   - `takePanorama`：目录 null/空白/绝对/含 `..` → 宿主层 `IllegalArgumentException`（端口前抛）；不在世界内 → `IllegalStateException`；宏根未初始化 → `IllegalStateException`；建目录/IO 失败 → `IOException`；端口不支持 → `UnsupportedOperationException`。**脚本层统一为可捕获的 rejected promise**——`GraalJsEngine.invokeAsync` 把 async 成员的同步异常转 `reject`（引擎源码实证；e2e 断言过），不存在“同步 throw 与文档不符”的问题。
   - 成功落定 = 例程消息；**六张 PNG 异步写入，resolve 不保证文件已存在**（JsMacros javadoc 同款 caveat，已写进 javadoc/`@zh`）。
3. **路径根** = `NeoMacrosFabric.macrosDir()`（配置 `macrosDir`，默认 `<config>/macros`），即 JsMacros “profile macro folder” 的对应物；**偏离记录**：JsMacros 要求 `folder` 已存在，本批 `Files.createDirectories` 按需创建（更宽松，已在 javadoc 写 “created on demand”）。
4. **读写一致**：`LifecyclePort.signText()` 改读编辑器缓冲（原读块实体正面）→ `writeSign` 后 `player.screen.getText()` 立即可见；副带修正：背面编辑现在读到的是被编辑面（原实现硬编码 FRONT）。
