## 关键实现笔记（后续 agent 参考）

1. `EventBus` 同步通道独立于 watchdog 存在（watchdog=null 时通道仍工作，只是不武装预算）——装配时"无 watchdog=不禁用"是合法组合
2. `once` 的去重用 AtomicBoolean 在**执行时**比对（入队到执行之间仍可能入队两次，但只执行一次）——比入队时失活更抗竞态
3. Java 17 工具链无 `Thread.ofPlatform()`（Java 21 API）——守护线程用经典 `new Thread` + setDaemon
4. 覆盖率门禁收窄：`def.*` 载荷 record 是数据样板（record 生成方法行数），已从门禁 excludes 掉，门禁只盯框架包——防止样板行稀释语义

## 遗留

- `AnnotatedClassScanner` 的 jar 扫描分支未被单测触达（目录 classpath 已覆盖）——jar 场景在嵌套 mod jar 运行时不可靠，T-021/T-023 装配时优先显式 register，扫描仅 dev/test 通道

- `events.waitFor`（Promise 化单次等待）依赖引擎 Promise 桥，属 T-021/T-023；框架已具备所需语义（订阅+谓词可叠加实现）
