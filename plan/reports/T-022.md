## 关键实现笔记（后续 agent 必读）

1. **TLA 模块的静态 eval 阻塞调用线程直至完成**——在 loop 上 eval 会死锁（解析永远进不来）。`importModule` 用**动态 `import(uri)`**：立即返回 Promise、loop 保持畅通、调用方在 loop 外等待结算。这是本次最重要的架构发现
2. `Context.close()` 默认**完全关闭**；enter 配对退出是 **`leave()`**（不是 close(false)）
3. 宿主函数跨界三定律：HostAccess.NONE 下（a）宿主 lambda 不可调用→ProxyExecutable；（b）宿主 Map 不可 for-in→Value API 建树；（c）宿主 Throwable 不可传入→glue `__neoNewError` 构造 guest Error
4. 绑定树构建在**构造期**（context 被 eval 线程持有），解析期只带引用——binding 内再走 onLoop 会死锁
5. `waiter`: `graalvm` 版本线与 JDK 基线绑定（24.x↔Java 17，25.x↔Java 21+）；升级随基线走
