## D 证据（5 项）

① `BlockStateHelper.getBlock` — BlockState 是无位置的不可变 DATA（12 号 §2.4），NeoMacros 的 `Block` 是**位置绑定活句柄**，不存在 JsMacros 那种类型级 `BlockHelper`；脚本持有句柄时反向取块无观察值（`block.state` 单向已在）。新建类型级方块类属 C（新 guest 类），超出任务卡落点，不硬写。
② `BlockStateHelper.getUniversal` — `UniversalBlockStateHelper` 是"任意属性名 → 动态方法分发"的类型化视图（JsMacros 专有动态派发形态，13 号 §5.10 标 ⚠ 未拍板）；等价面 = `state.props` 字符串属性表 + `is(id)`/`isProps()`，动态链按 12 号病灶 #2 对策不设。
③ `ChunkHelper.forEach(includeAir, callback)` — JsMacros 源码自带注释 "Maybe adapt this to the WorldScanner way?"；逐块 `MethodWrapper` 回调对 16×16×384 ≈ 98k 次进入 guest 属高频回调反模式（12 号病灶 #2）；等价面 = `world.findBlocks` / `world.scanBlocks`（13 号 §5.1，T-523 已落地：同步上限 + 异步分片）。
④ `HitResultHelper.resolve(HitResult)` — 静态工厂入参为 raw MC 类型（签名零 raw MC 铁律）；13 号 §5.10 已定 "`resolve` 工厂不设"，射线入口 = `world.raycast()`。
⑤ `HitResultHelper.Block.isMissed` — NeoMacros `world.raycast` 未命中返回 undefined（缺席 = undefined，`RayHit` 实例只在命中时产生），`isMissed` 在 NeoMacros 模型下恒 false 无观察值；等价配方 = 判断 raycast 返回 undefined。

## 偏离与回写

1. **命名偏离（任务卡成员名 → NeoMacros 名）**：
   - `getStartingBlock` → `chunk.minBlock`（13 号 §5.1 设计名 + 既有 `ChunkPos.minBlock()` 同值同名）。
   - `getOffsetBlock/getTopYAt` → `offsetBlock/topYAt`：绑定层对**带参** `get*` 保留全名（`GraalJsEngine.handleShape`），带 get 前缀会发布为 `chunk.getOffsetBlock`，与既有 `heightAt/biomeAt/lightAt` 去 get 的查询风格相悖；e2e 实测 `chunk.offsetBlock is not a function` 后定名。
   - BlockState 物理旗标沿用 JsMacros 语义名（`exceedsCube/hasComparatorOutput/blocksMovement/isSolid`）而非 Mojang 名——与类内既有 `isOpaque/isBurnable/isReplaceable`（T-513）保持一致；`blocksMovement` 不用 26.3 已删除的 Mojang 名 `blocksMotion`。
2. **对 T-513 报告的证据更正**（回写建议，docsx 禁改未动）：T-513 裁剪记录 "hasComparatorOutput 两端全缺" 系按 JsMacros 名检索所致，Mojang 名 `BlockStateBase.hasAnalogOutputSignal()` 在 1.21.6 与 26.3 **均存在**（javap 实证），本批已落地为 B；`blocksMotion()` 仅 26.3 移除（非"全缺"）。
3. **既有缺陷修复（任务卡外文件内顺手）**：`FabricWorldPort.stateExtras` 对干燥方块执行 `extras.put("fluid", null)`，而 `BlockData` 构造经 `Map.copyOf` **拒绝 null 值** → 干燥方块的 `blockAt` 全部 NPE 失败（T-513 引入的潜伏缺陷，既有测试因走 canned 数据未暴露）。改为仅潮湿时写键，`state.fluid` 读面语义不变（缺席 = undefined）。单测构造 `BlockData` 时同步避开 null 值。
4. **语义微调（已在 javadoc 写明）**：`allowsSpawning/shouldSuffocate` 按**传入坐标处当前世界中的方块状态**求值（JsMacros 用"接收者状态 + 给定 pos"；NeoMacros 状态恒为位置派生，实际用法两者一致）。
5. **边界口径**：未知 tag / 未知实体 id（谓词）= false；未加载世界、未 prim 或未知高度图类型、本地偏移越界、extras 缺席属性、实体命中的 inside = **undefined**；空 `containsAny`=false、`containsAll`=true。
6. **高度图 getter 判 A 的保留差异**：JsMacros `getOrCreateHeightmapUnprimed` 会在缺失时创建未 prim 的型；NeoMacros 只暴露已就绪型（T-511 既有行为），未 prim 型缺席 → undefined。
7. 注解：全部新成员 `@ApiSince("0.5.0")` + `@ApiMC("*")` + `@ApiLoader("*")`（+ `@ApiReadOnly`；raw 口另加 `@ApiPermission("java")`/`@ApiType("JavaObject")`），`AnnotationCompletenessTest` 三元组门禁绿；注释英文、`@zh` 中文。
