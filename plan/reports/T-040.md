## 交付清单

- `E2ERuntime`：真实引擎 + 真实事件框架 + 真实 ModuleManager + StubAdapter 装配（生产同款事件接线：tick 时钟推进、ALWAYS/WORLD 相位、chat receive）；`awaitSettle()` 等待全部 context loop 排空
- `StubAdapter`：lifecycle 注入（fireTick/fireGameStart/fireWorldJoin...）、chat 输出记录 + receive 注入、inWorld 状态
- `TestBridge`（`__test` 模块）：脚本自报 report(id, pass, detail)，桥实例经 binding registry 单源（修复自建实例与绑定实例不一致导致的 report 丢失）

- 基线场景 ×8（BaselineScenariosTest）：顶层/事件订阅、tick 自报、chat 回显（payload guest 化）、**onSync 取消（predicate 语义）**、storage 跨重启持久、reload 单订阅、域通配、异步原语

## 验证过程中修复的跨层缺陷（全部由本套件首测暴露）

1. **payload 未 guest 化**：EventBus 派发的 record 载荷在 HostAccess.NONE 下对 guest 不可读 → `Payloads.snapshot`（record→中立 Map 深拷）+ 引擎 `asGuestValue`（快照后 ProxyObject/ProxyArray 包装）
2. **sync 回调参数同病**：`events.onSync` 改为 **predicate 语义**（回调返回 truthy 即取消，Array.filter 风格）——绕开 host 回调对象无法安全跨界调用的问题；`CancelFlag` 仍为 bus 内部机制
3. **LoadTracker 生命周期错误**：end 在 load 完成即清除 → 事件回调/异步续延里 clock/storage 全失效 → 改为**常驻 loop 线程**（线程随 context 终止自动清理）
4. **promise null 落定 NPE**：Void future 落定调用 resolve(null) 抛异常被吞 → 无参 resolve
5. guest 函数参数适配：`adaptFunction`（Proxy 重入 loop）替代被 NONE 禁止的 Value.as(接口)
