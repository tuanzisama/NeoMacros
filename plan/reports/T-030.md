- 状态: done

## 交付清单

- `FabricLifecyclePort`：Fabric ClientLifecycle/ClientTick/ClientPlayConnection 事件桥 → 生命周期/tick/world-join-leave sink（主线程、注册序触发）+ `inWorld` 供给
- `FabricChatPort` + `ChatReceiveHub`：say（连接发送）/log（聊天 HUD）/actionbar（HUD 覆盖消息）输出 + 接收源扇出
- `ChatDisplayMixin`：注入 `ChatComponent.addServerSystemMessage`/`addPlayerMessage`（官方名直接注入，unobf 无 refmap；defaultRequire=1）；本模组自身的 client system message 不回环
- `NeoMacrosFabric` Bootstrap：装配 ScriptRuntime（GraalJS 引擎 + 端口 + 事件目录（scanPackage def 包）/总线 + 线程池）、端口 sink → 总线发布（tick 事件同时推进 TickClock）、每 tick 排空主线程调度、`/neomacros status|list`
- `neomacros.mixins.json` + fabric.mod.json mixins 引用；product 测试依赖 + `ChatReceiveHubTest`
- 26.3 官方名地面真值（javap 实证）：`Minecraft.level`（public 字段）、`mc.gui.hud`（public 字段）、`Hud.setOverlayMessage(Component,boolean)`、`Hud.getChat()`、`ChatComponent.addClientSystemMessage/addServerSystemMessage/addPlayerMessage`、`ClientPacketListener.sendChat(String)`
