## 关键实现笔记（后续 agent 参考）

1. **javadoc 自定义块标签 API**（调试实证）：未注册/已注册的自定义标签都是 `UnknownBlockTagTree`，`DocTree.Kind.UNKNOWN_BLOCK_TAG`；`getTagName()` **不含 @**；正文英文部分取 `getFirstSentence()+getBody()`（`getFullBody()` 会把块标签带进来，@zh 会泄漏进英文页）——已封装进 `DocletSupport`，勿再踩
2. **Gradle test 输入追踪缺口**：`src/test/fixtures`、`src/test/snapshots` 不属于任何 source set，内容变更不会触发 test 任务重跑——已在 build.gradle.kts 用 `inputs.dir` 显式声明
3. **fixture 源码不经编译器**（javadoc 直读），import 错误只有生成期才暴露——改 fixture 后必须跑一次 check
4. `tscPath` 走 gradle property（Provider 必须 `.get()`，否则 systemProperty 收到 toString 垃圾值——已修复并留注释）
