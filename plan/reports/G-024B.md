## 命名与形态决策

1. **句柄不变**：三个分组句柄（`ChatOptions/ControlOptions/AccessibilityOptions`）由 G-024 建好并注册（`NeoMacrosFabric.registerGuestType`、`E2ERuntime` 各 7 类已含本批三类），本批只在其上加成员，**无需改动任务卡外的注册文件**。
2. **词表**：读属性、`OptionsData` 分量、`setOption(name, …)` 写名共用 **Mojang 选项词表**，与既有 `client.option(name)`（T-515 白名单）同名：`chatVisibility/chatColors/chatLinks/chatLinksPrompt/chatOpacity/textBackgroundOpacity/chatScale/chatLineSpacing/chatDelay/chatWidth/chatHeightFocused/chatHeightUnfocused/narrator/autoSuggestions/hideMatchedNames/reducedDebugInfo/sensitivity/invertMouseY/mouseWheelSensitivity/discreteMouseScroll/touchscreen/rawMouseInput/autoJump/toggleCrouch/toggleSprint/showSubtitles/backgroundForChatOnly/darkMojangStudiosBackground/hideLightningFlash`。上表「改名」即 JsMacros 名 → Mojang 名。
3. **无参状态一律属性、写动作一律 `setXxx` → `Promise`**（沿 G-024 拍板：`enableVsync` 之类与属性同名会撞 `handleShape` 键，故 setter 统一带 `set` 前缀）。JsMacros 的 `enableXxx/toggleXxx/showSubtitles/reduceDebugInfo/invertMouse` 全部归一为 `setXxx`。
4. **读写成对 + 回读校验**：三个分组的全部写动作走 G-024 的 facade 单点 `writeOption(name, value)` → `ClientPort.setOption` 主线程落 `CompletableFuture` → `verifyValue(component, …)` 比对（数值按 double 比、字符串忽略大小写），不一致 reject 并带 `requested/stored`。**每分组 ≥1 个写→回读往返断言**见「测试」。
5. **键位读面走独立端口方法**：`control.keys/categories/keyBindsByCategory` 不进 `OptionsData` 快照（避免每次读 `options.fov` 都翻译 ~100 条 `Component`），新增 `ClientPort.keybindCatalog()` + 新 record `ports/model/KeybindCatalogData`（names/categories/bindsByCategory）。实现侧复用既有 `OptionsKeyMappingsAccessor.neomacros$keyMappings()` 读公有 `keyMappings` 面——**未新增任何 mixin**，`neomacros.mixins.json` 未改。
6. **缺席语义**：`options()` 空 → 三组属性全部 `undefined`、`keys/categories` = `[]`、`keyBindsByCategory` = `{}`、`getKeyBindsByCategory(未知分类)` = `undefined`；写动作 reject（`game options are unavailable`）。
7. **注解**：新增成员全部 `@ApiSince("0.5.0")` + `@ApiLoader("*")` + `@ApiMC("*")` 显式三注解，读属性另加 `@ApiReadOnly`；注释英文 + `@zh`（`AnnotationCompletenessTest` 门绿）。

## 与 JsMacros 的语义差异（有据）

1. **枚举读值**：JsMacros `getChatVisibility()` 取平移键末段（1.21.6 得 `".full"`，其 `>=1.21.11` 分支取 `name()` 后再 `substring(lastIndexOf('.'))` 会越界），`getNarratorMode()` 得 `".all"`——读值随版本漂移且带前导点。NeoMacros 统一取 `Enum.name()` 小写：`full/system/hidden`、`off/chat/system/all`，与写词表同形（对齐 G-024 `attackIndicator/particles` 的口径）。
2. **枚举写校验**：JsMacros 未知名静默保留原值；NeoMacros 未知名 `Enum.valueOf` 抛错 → Promise reject（沿 G-024 拍板「枚举写解析未知名 reject」）。大小写不敏感两者一致。
3. **`touchscreen` / `rawMouseInput` 已移除项**：JsMacros 在移除版本上读常量、写空操作（永不报错）。NeoMacros 读同样给常量（26.2+ `false`、26.3+ `true`），写为空操作后仍走回读校验——**请求值与常量一致时 resolve，不一致时 reject 并给出 stored 值**，比静默吞掉更诚实；javadoc 已写明。
4. **键位表词汇**：`getKeyBindsByCategory` 的键沿 JsMacros 用**本地化**绑定名（`Component.translatable(name).getString()`）与按键标签，分类键沿 JsMacros 表达式（1.21.6 = `key.categories.movement`，26.x = `category.id().toLanguageKey()` = `minecraft.movement`）——同版本下与 JsMacros 逐字一致，但跨版本会漂移（JsMacros 自身即如此）。`control.keys` 则始终是稳定的 `key.forward` 形注册名。
5. **`getKeyBinds()`（无参全量）不在本批 89 内**：gap 既有 triage 已判 `status=renamed`、`target=input.keybinds`（`gap.json` 原文），脚本侧走 `neo.input.keybinds`，本批不重复造。
6. **`setFovEffect(boolean)` 不设第二成员**：见「A 判定说明」（`handleShape` 按名去重，同名重载只保留一个且顺序不定）。
7. **`areLightningFlashesHidden` 只读**：JsMacros 本就没有写面（其后那个 `setFovEffect(boolean)` 是 FOV 便捷写，不是闪电开关），本批保持只读以维持 89 签名的 1:1；vanilla `hideLightningFlash` 可写，如需可后续补 `setHideLightningFlash`（89 外扩展）。
8. **`getCategories` 版本门阈值**：JsMacros 用 `>1.21.8`，本仓既有 `FabricInputPort` 对同一 API 用 `>=1.21.11`；四个编译节点（1.21.6 / 26.1.2 / 26.2 / 26.3）两条件结果相同，本批沿仓内既有阈值 `>=1.21.11`（1.21.9–1.21.10 非编译节点，差异不生效）。
