## 关键设计决策（实施期审阅确认）

1. **逐形状键控端口**：`putShape(layer, shape, spec)` upsert 是组件句柄的基石（同 id 重投 = 变更即生效）；即时原语用自增 `r*` id 追加，保住"累积、只整层清"的 0.1.0 语义。
2. **双深度桶**（26.x）：javap 实证 `LevelRenderer` 把 gizmo 分标准/alwaysOnTop 两桶，故第二个常驻 `frameGizmoTop.setAlwaysOnTop()`；`cull==false` 进 top 桶、`cull==true` 与全部即时原语进标准桶（原语历史行为 = 深度测试，语义不漂移）。1.x 无 always-on-top 的 `RenderType.lines()`，全部深度测试 + `fill` 走 `debugQuads`（视觉差异见遗留 5）。
3. **零 alpha 规则**：打包色 alpha 字节为 0 而 RGB 非零 → 判不透明；全零保持透明；`setColor(color, alpha?)` 显式 alpha 可保留 0（JsMacros 同款，单测 `boxColourAndAlphaFollowTheJsMacrosRules` 锁死）。
4. **入参 `long`、出参 `int`**：与 G-030 决策⑤同口径——引擎 `convertArgument` 的 `asInt()` 拒绝 >2^31 的 JS 字面量，`setColor(0xFF00FF00)` 类调用必须走 `long`（e2e `wideColor` 用例实测通过）。
5. **owner 命名空间 + 卸载钩子**：设计 §4.3"同 owner 隔离"的实现；`LoadTracker.current()` 为既有 bindgen 设施（非新依赖）；owner 缺失（控制台/宿主）保持裸键，与前 owner 行为一致。
6. **`reAddElement` 比 JsMacros 严**：JsMacros 允许重复入列，键控端口每元素一格 → 重复挂载 no-op、跨图层挂载抛错（javadoc/用例写明）。
