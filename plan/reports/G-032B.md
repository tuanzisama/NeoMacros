### 脚本面（对照 G-001 §4.2）

```ts
interface Draw2DElement {                    // @ApiClass(name="Draw2DElement", kind=HANDLE)
  readonly id: string;  readonly disposed: boolean;
  readonly layer: HudLayer;                  // = JsMacros getDraw2D()
  readonly parent: HudLayer;                 // v1 恒为所在层（setParent 判 D，P3 nested）

  readonly x: number | string;  readonly y: number | string;
  setX(v: number | string): this;  setY(v): this;  setPos(x, y): this;
  readonly width: number | string;  readonly height: number | string;
  setWidth(w): this;  setHeight(h): this;  setSize(w, h): this;
  readonly scale: number;      setScale(n: number): this;       // n > 0，否则 throw
  readonly rotation: number;   setRotation(deg: number): this;  // 归一 [-180, 180)
  readonly rotateCenter: boolean; setRotateCenter(v: boolean): this;  // isRotatingCenter → 属性
  readonly zIndex: number;     setZIndex(z: number): this;      // core 内重排，零端口流量
  readonly visible: boolean;   setVisible(v: boolean): this;
  readonly bounds: Bounds;                     // { x, y, width, height }（求值 × scale）
  readonly scaledWidth: number;  readonly scaledHeight: number;
  readonly scaledLeft: number;   readonly scaledTop: number;
  readonly parentWidth: number;  readonly parentHeight: number;
  moveTo(x: number | string, y): this;         // = setPos 别名（JsMacros moveTo）
}
interface Bounds { readonly x: number; readonly y: number;
                   readonly width: number; readonly height: number; }   // @ApiClass DATA
// render(GuiGraphics,...)、setParent(IDraw2D) → 判 D（见映射表）；alignTo/align/moveToX/moveToY → G-034C
```

## 关键设计决策（实施期）

1. **状态模型迁入 components（`ElementSpec`）**：基类与子类必须读写同一份不可变状态，而原 `HudScene.Spec/Coord/Kind` 是 render 包包私有、跨包不可达。迁移后 `Backend` 收敛为 `spec()/publish()` 两法的**最小固定接口**——G-034 加组件字段只改 `ElementSpec`（+`with*`）与 `HudScene.emit`，**基类文件不再动**（§6.2"基类 API 稳定"的落点）。
2. **`Backend` 五法桥**：匿名实现内嵌于 `HudScene.backendFor(Cell)`（读 volatile、同步发布、z 变更推进代数、视口/失效探针）；句柄构造改 `(id, layer, backend)`。`protected backend()` 只对子类可见——引擎 `getMethods()` 与文档模型只收公有成员，测试锁死 `backend/spec/publish` 不泄漏脚本面。
3. **原始值/求值值双形**：`x/y/width/height` 属性读**原始形态**（数字或 `"50%"` 往返，设计 §4.2 `number|string`），`scaled*/bounds/parent*` 给**求值数值**（JsMacros `getScaledWidth` 等 1:1）——百分比不丢形，对齐数学有整数可用。
4. **命名裁定（设计优先）**：`getDraw2D` → 属性 `layer`（设计 §4.2 字面；v1 返回层而非"嵌套 overlay"，叫 `draw2D` 反而误导 compat 桥）；`isRotatingCenter` → 属性 `rotateCenter`（设计 §4.2 字面）。两者在 gap 审计各需一条 `MEMBER_ALIASES`（遗留3，JsMacros-Dump 不属本任务可改范围）。
5. **JsMacros 行为 1:1 的校验与归一**：`setScale≤0` 抛、负尺寸抛、`setSize` 先宽后高 quirk、`setRotation` 归一 `[-180,180)`——含 upsert opts 路径同校验（`scaleOf/rotationOf`）。
6. **元素 z 零端口流量**：`publishCell` 只在 `zIndex` 变化时 `generation++`，`orderedSnapshot` 脏时重排——e2e 用 `events()` 恰 1 条 `add` 断言（层 z 才走 `setLayerZ`）。
7. **`Bounds` 为 @ApiClass DATA record**：record 跨界经 `Payloads.snapshot` 成脚本对象（`el.bounds.x`），d.ts 走独立 `interface Bounds`；不注册 guest type（`MousePos/FileStat` 先例，DATA 不可构造）。
8. **fluent 返回基类型**：`setX(...): Draw2DElement`（任务卡字面签名；JsMacros 同为返回 `Draw2DElement`）——脚本链式无感，Java 子类如需协变可自行覆写（未要求）。

## 偏离清单（与 JsMacros / 任务卡 / 设计稿）

| # | 偏离 | 理由 |
| --- | --- | --- |
| ① | `HudScene.Spec/Coord/Kind` **迁移**为 `components/ElementSpec`（新文件） | 基类/子类跨包读写状态的唯一最小解（决策1）；行为零变化，测试不感知 |
| ② | `getX/getY/getWidth/getHeight` 返回**原始** `number\|string`，非 JsMacros 的求值 `int` | 设计 §4.2 字面（`readonly x: number|string`）；求值整数由 `getScaledLeft/Width` 等承载（JsMacros 语义 1:1），绝对像素场景两者同值 |
| ③ | setter 参数 `int` → `Object`（`@ApiType("number \| string")`） | §3.4 百分比坐标类型放宽（设计稿优先于任务卡字面签名）；名字/调用面 1:1，`int` 实参照常工作 |
| ④ | `render`/`setParent` 判 **D**（63 中仅有的 2 个 D） | G-001 §2.2/§4.6/§3.4 明判：raw `GuiGraphics` + 每帧进脚本；nested parent 归 P3 |
| ⑤ | 脚本属性名 `layer`/`rotateCenter` 与 gap 成员名 `getDraw2D`/`isRotatingCenter` 不同名 | 设计 §4.2 字面拍板；审计以 `MEMBER_ALIASES` 回写承接（遗留3），语义等价 100% |
| ⑥ | `text/rect` 的 `scale`/`rotation` opts 由"静默忽略"改为**入状态**（渲染应用仍归 G-034） | G-032 偏离⑧ 的"收不发"完整化：状态面已存在，setter 与 opts 同源校验；用户可见绘制行为不变（paint 仍不应用）。`shadow` opts 维持忽略（无字段，归 G-034） |
| ⑦ | 文本元素 `getWidth/getScaledWidth` v1 恒 0（未设 `w` 时） | JsMacros 用 `IntSupplier` 量文本；core 无字体度量，`DrawContext2d.textWidth`/`ChatPort.textWidth` 注入归 G-034（遗留1）。rect/显式 `setWidth` 不受影响 |
| ⑧ | `bounds` 定义 = 求值原点 + **乘 scale** 截断宽高 | 设计 §3.4 字面"缩放/百分比求值后"；与 `getScaledWidth/Left` 同源（测试锁死），供 G-034C 对齐直接取用 |
| ⑨ | `setSize(w, h?)` 的 `h` 可选未做（双参必填） | 任务卡/JsMacros 字面 `setSize(int, int)`；引擎 `convertArgs` 对缺省原参传 null 会解包失败——必填为引擎约束下的 1:1 |
| ⑩ | 新增 `visible/setVisible`、`bounds`（不在 63 内） | G-001 §4.2 交付面 + G-032 遗留1 点名（"扩全量…bounds"）；`visible` 为 upsert opts 已有状态的读写面 |
| ⑪ | `Draw2DElement` 由 `final` 改开放 + `Bounds` 新类型 | 验收"作为 G-034/034B/034C 的父类先落地"的必要条件；`@ApiSince("0.5.0")` 全成员按任务书硬规则 |

**与任务卡冲突的裁定**：任务卡落点 `product/adapter/FabricHudRegistry.java` 已由 G-032 删除（其偏离⑤），本批无涉；63 签名中 `render/setParent` 按设计稿判 D、`*Builder` 类按拍板②不建——均为"设计稿优先"（G-032 同款裁定口径）。
