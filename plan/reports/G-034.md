### 脚本面（对照 G-001 §4.1/§4.2）

```ts
interface HudLayer {
  text(id, text, opts?: TextOptions): Draw2DText;    // 协变收窄（G-032 偏离②演进）；opts + shadow
  rect(id, opts: RectOptions): Draw2DRect;           // 协变收窄
  line(id, opts: LineOptions): Draw2DLine;           // 本批新（G-032 addLine×12 的桥接目标）
}
type LineOptions = { x1: number; y1: number; x2: number; y2: number,
                     color?: Color; width?: number; rotation?: number,
                     zIndex?: number; visible?: boolean };

interface Draw2DText extends Draw2DElement {          // 全部继承面见 G-032B/G-034C 报告
  setText(text: string): Draw2DText;  readonly text: string;
  setShadow(shadow: boolean): Draw2DText;  hasShadow(): boolean;
  setColor(color: number | string, alpha?: number, b?: number, a?: number): Draw2DText;
  readonly color: number;
  // 度量（继承面的值由组件播种）：width = 字体量宽、height = 行高、
  // scaledWidth = 量宽 × scale（JsMacros 1:1）
}
interface Draw2DRect extends Draw2DElement {
  setX1(x: number): Draw2DRect;  readonly x1: number;   // … setY1/getY1/setPos1/setX2/getX2/setY2/getY2/setPos2
  setColor(color, alpha?, b?, a?): Draw2DRect;  readonly color: number;
  setAlpha(alpha: number): Draw2DRect;  readonly alpha: number;
  // getWidth = |x2−x1|、setWidth 锚定较小角（JsMacros 1:1，基类面）
}
interface Draw2DLine extends Draw2DElement {
  setX1(x: number): Draw2DLine;  readonly x1: number;   // … 端点八签名 + setPos2（同构矩形角点面）
  setStrokeWidth(width: number): Draw2DLine;  readonly strokeWidth: number;   // 笔画粗细（偏离①）
  setColor(color, alpha?, b?, a?): Draw2DLine;  readonly color: number;
  setAlpha(alpha: number): Draw2DLine;  readonly alpha: number;
  // width（继承）= |x2−x1| 横向跨度；scaledLeft = min(x1,x2)；moveTo 平移两端点
}
// 判 D 不入面：render/setParent（G-032B 既判）、Text 富文本 setText(TextHelper)/TextBuilder、
// Builder.createElement（upsert 承接）；hasShadow 是方法（引擎只折 get*/is*）
```

## 关键设计决策（实施期）

1. **几何统一为"最小角盒 + 方向标志"**（本批最重要的结构裁定）：`Rect/Line` 的端点/角点是**耦合几何**（动一个角另一个跟着变），而基类 setter（`setX/setPos/setWidth/moveTo`，对齐面也走 `moveTo`）只写 `x/y/w/h`。若把端点存为独立字段，继承面一写就与盒脱节；若让子类重声明 `getScaledLeft` 等，违反 G-034C 契约（重声明会把 `handleShape` 绑定类挪到子类、破坏"引擎面 = 基类面"）。**解：spec 盒恒为 min 角原点 + 非负尺寸（权威），`flipX/flipY` 记录第一角/端点方向，端点在读时派生**——于是 `moveTo` 平移、`setWidth` 锚小角、对齐数学（`scaledLeft=min`、`scaledWidth=|dx|`）与 JsMacros `Line/Rect` 逐条同式，且任何继承写都不脱同步。第一角方向可观测（`getX1` 可非最左），反序角点序保留。
2. **文本度量 = 组件播种进盒**（G-032B 遗留①闭环）：`layer.text` upsert 与 `setText` 把 `port.textWidth(text)`/`port.textLineHeight()` 写入 `spec.w/h`——**基类 `getWidth/getScaledWidth/bounds/align` 零改动即得 JsMacros 度量语义**（"缓存于 setText、不在 getter 刷新"逐字同款），不给 `Draw2DText` 加任何几何重声明。度量走 `RenderPort.default textWidth`（`length*6`）+ Fabric 覆写真字体（`FabricChatPort.textWidth` 先例，非渲染线程读 font 有先例）。
3. **scale/rotation 渲染应用归 paint 路径**（G-032B 遗留②/G-032 偏离⑧ 收尾）：`HudScene.withTransform` 在 `emit` 外套 `DrawContext2d.transform` 作用域；**默认 1/0 直接裸画**——既有图元断言（HudScenePaintTest/Alignable/g032b 等）零破坏。单枢轴语义 = `T(p)·S·R·T(-p)`（定位角为枢轴，均匀缩放与旋转可交换）；`rotateCenter` 时嵌套第二作用域（外层缩放绕定位角、内层旋转绕**绝对中心**——矩阵复合后恰为绕缩放后中心，精确等价 `translate(pos);scale;rotate(center)`）。线的枢轴 = 第一端点（`rotateCenter` 为中点），JsMacros `Line` javadoc 逐字同款。
4. **线原语退化在接口默认层**（G-001 §6.2）：javap 证明两节点都无任意斜线 GUI 原语（1.21.6 仅 `hLine/vLine`），`DrawContext2d.line` 的 **default = DDA 步进 `rect` 填充**——Fabric 适配器零分支继承即得四节点一致渲染；e2e/core 记录上下文覆写为单条 `line` 图元（G-001"core/e2e 断言的是 line 图元"）。签名较 §5.2 增加 `width` 参（线宽必须过端口；中立方法零脚本面，偏离⑧）。
5. **transform 实现零 `//?`**：javap 实证 `GuiGraphics.pose()`（1.21.6）与 `GuiGraphicsExtractor.pose()`（26.3）**同签名返回 `org.joml.Matrix3x2fStack`**，JOML `pushMatrix/translate/rotate/scale/popMatrix` 两代同在 → `extractor.pose()` 字面调用安全；文本 shadow 用两节点都有的 `text/drawString(..., boolean)` 重载（既有替换对覆盖）。**本批零新增 `//?` 分支**，四节点编译绿佐证。
6. **颜色面集中在组件、双形单入口**：`setColor` 折叠四元分派（1/2/3/4 元）+ 5 个 `@ApiInternal` 宿主重载（Java 侧任务卡形 1:1）；`parseColor` 双入口迁入 `ElementSpec`（`HudLayer.colorOf` 委托，行为零变化）。alpha 语义逐字 JsMacros：替换顶字节、不钳制、`getAlpha = color >>> 24`。
7. **句柄身份与 fluent**：`HudScene.upsert` 按 Kind 工厂构造子类句柄（同型保句柄、异型替换失效语义不变）；`text/rect` 协变收窄返回子类（Java 调用方赋基类仍兼容，脚本无感）；组件 mutator 自持 `requireAlive()`（`backend().disposed()` → 同消息 `IllegalStateException`）+ `publish` 双保险（G-034C 契约"子类 mutator 经 publish 出版自动获得失效复查"）。
8. **`hasShadow` 保持方法**：引擎只把 `get*/is*` 折成属性，`has*` 按名绑定为方法——与任务卡 `public boolean hasShadow()` 字面一致（`isRotatingCenter→rotateCenter` 是设计稿点名的属性化，此处无点名）。

## 偏离清单（与 JsMacros / 任务卡 / 设计稿）

| # | 偏离 | 理由 |
| --- | --- | --- |
| ① | `Line.setWidth/getWidth/width`（任务卡 = 笔画粗细）落点为基类 `width` 面（= 横向跨度 `|x2−x1|`）；笔画粗细另立 `setStrokeWidth/getStrokeWidth/strokeWidth` | G-034C 契约"子类不得重声明基类同名成员"（重声明挪 `handleShape` 绑定类、破坏继承测试）——`getWidth` 无法覆写；`width` 若改存笔画则 `scaledWidth/bounds/对齐` 全错。跨度语义对"线的宽度"自洽，笔画以独立名承载；gap 审计 `Line.width` 名字面命中（语义注）+ `strokeWidth` 为任务外超集（G-032B `visible/bounds` 同款口径） |
| ② | `Line/Rect.setPos(4 参)` 无同名成员 → 折叠 `setPos1+setPos2` 链 | 与基类 `setPos(2 参)` 同名重载按 G-033 铁律①只留一个且顺序不定；能力 100% 承接（`setPos1` 后 `setPos2`）；审计需 `setPos` arity 注 |
| ③ | `Text.setText(TextHelper)`/`getText(): TextHelper`/`Builder.text(TextHelper|TextBuilder)` 判 D；`getText` 落为 String 属性 `text` | 富文本（样式/悬浮/点击）不在 G-001 §4.2 v1 设计面（`Draw2DText { text, color, shadow }`）；NeoMacros 无 `TextHelper`/`TextBuilder` 类型（`neo.Text` 已占名，拍板①冲突族）；读回纯文本能力由属性 `text` 承接 |
| ④ | `Rect.moveTo` 设**最小角**（基类面）；JsMacros 设第一角 | 反序角点（`x1>x2`）时两者不同；常规角序（第一角=最小角，`layer.rect` 原生与 upsert 全部如此）逐字同值。端点视图 `setX1/setPos1` 仍可表达任意序（flip 保留） |
| ⑤ | `Rect` 负宽不接受（基类 `setWidth` 拒负，G-032B 校验测试锁死）；JsMacros `Rect.setWidth` 接受负值反序 | G-032B 既定校验为既有测试面，破坏成本高；反序需求由 `setX1/setX2` 跨越表达（flip 翻转），能力不丢 |
| ⑥ | `Text.setScale` 拒绝 ≤0（基类校验）；JsMacros `Text.setScale` 接受负值（拒 0） | 同⑤：基类校验为 G-032B 锁死面；负 scale 的渲染语义（镜像）非 v1 需要 |
| ⑦ | 颜色原样存储，不复刻"零 alpha 非零 RGB → 不透明、纯黑保持透明"怪癖 | G-032 `colorOf` 既定口径（拍板④ 归一不含该规则）；只在组件 `setColor` 加会与 upsert opts 路径不一致；怪癖记录待 G-004 compat 评估 |
| ⑧ | `DrawContext2d.line` 签名含 `width`（§5.2 字面无）；`textWidth` 落 `RenderPort` 而非 `DrawContext2d`（§5.2 二选一） | 线宽必须过端口（否则 stroke 无法渲染）；度量在 `setText`/upsert 时发生（非 paint 路径），`DrawContext2d` 不可达——§5.2 原文即允许"上提为 RenderPort default" |
| ⑨ | `layer.line` 的 `x1..y2` 只收数字（不收百分比字符串）；角点 setter 写入时把百分比解析为绝对值 | JsMacros 端点为 `int`（1:1）；`layer.rect` 的 x/y/w/h 百分比面（G-032）不受影响；线的百分比端点非设计面 |
| ⑩ | 任务卡外新增：`strokeWidth` 面、`setColor(String)` 等 5×3 个 `@ApiInternal` 宿主重载、`HudLayer.measureText*`、`layer.line` 的 `scale` opts 超集 | 宿主重载 = G-034C 先例（Java 调用形 1:1，零脚本/文档面）；其余为必要衔接或无害超集，全部 `@ApiInternal` 或文档可注 |
| ⑪ | `Draw2DText` 无 `setAlpha/getAlpha`（任务卡 Text 无此成员） | 最小面贴任务卡；文本 alpha 可经折叠 `setColor(color, alpha)` 写入、读回 `color >>> 24` |

**与任务卡冲突的裁定**：`classes: [Text, Rect, Line, Builder]` 中三个 `Builder` 判"不建类"（拍板②，G-001 §4.6/§11 明判，G-032B 同款）；`render`/`setParent` 判 D（G-001 §4.6/G-032B 既判）；Text 富文本三签名判 D（设计稿优先）——均为"设计稿优先"裁定口径。

## 给 G-034B 的接口面（Image / Item）

1. **组件类模板**：`class Draw2DImage extends Draw2DElement`，公有构造 `(String id, HudLayer layer, Backend backend)`；私有 `requireAlive()`（`backend().disposed()` → `IllegalStateException("element no longer valid")`）；mutator = `requireAlive()` → `backend().publish(backend().spec().withXxx(...))` → `return this`；getter = `backend().disposed() ? null : backend().spec().xxx()`。**不要重声明任何基类成员**（对齐/几何/z/生命周期全继承；G-034C 契约）。
2. **状态扩展点**：`ElementSpec` 加 Image/Item 字段（`texture/imageX/region…/overlay/stack` 等）+ 对应 `with*`（照 `withShadow` 抄）；`Kind` 枚举追加 `IMAGE`/`ITEM` ——**`HudScene.newHandle` 的 switch 是穷尽的，编译器会强制你补工厂分支**；`emit` 同理强制补绘制分支。
3. **upsert 面**：`HudLayer.image(id, opts)` / `item(id, stack, opts)` 协变返回 `Draw2DImage`/`Draw2DItem`（照 `line` 抄：`ensureAlive + requireElementId + 建 spec + (Draw2DXxx) scene.upsert(...)`）；G-032 拆出的 `addImage×12`/`addItem×24` 折叠承接照本报告 §G-032 拆出节的口径写。
4. **颜色面**：直接复制 `Draw2DRect` 的折叠 `setColor(Object,Object,Object,Object)` + 5 个 `@ApiInternal` 宿主重载 + `getColor/setAlpha/getAlpha`（`ElementSpec.parseColor` 双入口现成）。
5. **端口/原语**：`DrawContext2d.sprite` 已在（纹理）；**`item` 原语仍缺**——G-001 §5.2 归 G-034B，按 §6.2 `extractor.item`⚠ 走 javap spike + `//?`（`GuiGraphics.renderItem` 两节点核对后落 default/覆写）；Stub/Recording 记录器照 `line` 的模式补 `item` 图元。
