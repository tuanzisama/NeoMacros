## 关键实现笔记（后续 agent 参考）

1. **future 完成线程断言的写法**：必须在 future 完成前挂 `whenComplete` 才能捕获完成线程（完成后挂的回调跑在注册线程上——CF 语义）——测试基建 `captureCompletionThread` 已封装该模式
2. `ContextEventLoop.close` 必须中断 + join worker，否则 close 后的 `isRunning()` 断言有竞态
3. `blockingJoin`/`runOnMain` 的死锁判定分三层：主线程内联放行（无等待）、主线程阻塞等待拒绝、桥接任务内嵌套拒绝——与 03 §2"内联执行"和 §3 规则 5"抛错"两处表述的逻辑合成，已按此实现并测死
4. Java 17：无 `Thread.ofPlatform()`；lambda 捕获循环重赋值变量需 final 局部中转
