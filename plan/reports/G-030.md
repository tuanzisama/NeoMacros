## 关键设计决策（实施期）

1. **静态工厂 → `SelfConstructing` 构造器**：引擎对 `@ApiClass` 的 static 成员既不进文档模型也不进 `handleShape`，`createWidget`×2 落为 `new CustomImage(w,h,name)` / `new CustomImage(path,name)`（无参构造 = 引擎工厂壳，`construct(Object[])` 按参分发——`ItemStackBuilder` 同款）。
2. **重载折叠为单成员**：`handleShape` 按名 `putIfAbsent`，同名重载有且仅有一个可达（顺序不定）→ JsMacros 的 2/2/2/2 组重载全部折叠为"`@ApiOptional` 尾参"单成员；Java 调用面配 `@ApiInternal` 捷径重载（引擎/文档双侧过滤）。
3. **`drawImage` 十参是角点语义**：JLS `drawImage(img, dx1,dy1,dx2,dy2, sx1,sy1,sx2,sy2)` 取矩形对角而非"原点+尺寸"（AWT 实测：按尺寸传参只会画出 1px/空图）；按 CE 源码同款 `x..x+width` 换算（CE `CustomImage.java:353` 逐字对照）。
4. **标识符换本 mod 命名空间**：`neomacros:image/<name>`（CE `minecraft:jsmimage/<name>` 对位）；名字经小写字母/数字/`/._-` 字符校验（`Identifier` 路径规则），非法抛 IAE。消费位 `DrawContext2d.sprite(textureId)`（G-034B）按同一 id 直接 blit。
5. **ARGB 跨界口径（重要）**：引擎 `convertArgument` 的 `int` 分支用 `Value.asInt()`，**拒绝 >2^31 的 JS 数字**（e2e 实测 `0xFF112233` 直接 ClassCastException）。本类对策——**入参 `long`**（`setPixel/setGraphicsColor/setXorMode/clearRect.color/nativeARGBFlip`，`asLong` 全域/有符号两种写法都接受、`(int)` 截断落 32 位），**出参维持 `int` 有符号**（与 CE/JsMacros 的 Java int 跨界行为逐位一致；`|0` 归一到全域写法）。引擎级修复（`fitsInInt ? asInt : (int) asLong`）属跨车道改动，列遗留 5。
6. **AWT 后端**：core 直接用 `BufferedImage+Graphics2D`（JDK 自带、ArchUnit 只禁 MC/Fabric 包、四节点无关）——30+ 绘制原语与 CE **同一套 Java2D 实现**，语义天然对齐（xor/clip/基线/弧度方向均 AWT 规范原文）；`ImageIO` 负责 PNG 编解码。
7. **文件根 = 配置目录**：CE 用 `config.configFolder`，NeoMacros 对位 `config/neomacros`（`ConfigDirFsBridge`，越界拒绝）——**与 `neo.fs` 的游戏目录根不同**（`neo.fs` 对位的是 JsMacros 的 fs 面，两者各自的 JsMacros 源头本就不同目录）；`loadImage/saveImage` 保持**同步**（JsMacros 返回类型是同步值，compat 无法把同步调用改成 Promise）。

## 偏离清单（与 JsMacros CE / 任务卡）

| # | 偏离 | 理由 |
| --- | --- | --- |
| ① | `getImage()` 返回**不可变 PNG 快照**（CE 返回可变内部 `BufferedImage`） | 12 号"包装层签名零 raw"：AWT 类型不可跨界；回灌经 `drawImage(Image,…)` 等价可达；javadoc 已写明 |
| ② | `getPixel/getGraphicsColor` 返回**有符号 32 位** | 与 CE 逐位一致（Java int 跨 Graal 即有符号）；javadoc 给出 `\|0` 归一写法 |
| ③ | `saveImage` 写失败**抛 `UncheckedIOException`**（CE 记日志后照常返回） | 静默失败不可调试；仅真实 IO 错误路径偏离，成功路径语义不变 |
| ④ | `update()` 返回 **Promise**（CE 阻塞等主线程）；构造期上传为 **best-effort 不等待** | 15 号"异步动作 Promise"硬规则 + G-001 §8.3"注册/上传走主线程 + Promise"；`update()` 是权威等待点，构造期上传失败可在 `update()` 观察 |
| ⑤ | **HudApi/FabricHudRegistry/Image.java 零改动**（任务卡落点三文件之一） | G-001 §5.1 把纹理注册表归口 `RenderPort`（`sprite` 消费位同侧）；`hud.texture` 脚本面 = G-038；`Image` 已具备 `width/height/getBytes` 构造面够用。落点偏离按 15 号"需要跨任务改共享文件先写报告"口径记录 |
| ⑥ | `new CustomImage(path, name)` 不可读时**抛错**（CE 返回 null） | `new` 无法返回 null；`loadImage` 方法面保留"失败 = undefined"的 CE 口径 |
| ⑦ | 类名/标识符命名空间、`nativeARGBFlip` 实例面 | 见决策④⑤（引擎约束，非语义缩水） |

**与任务卡/设计稿冲突的裁定**：任务卡"落点含 HudApi/FabricHudRegistry"与 G-001 §5.1"纹理走 RenderPort"冲突 → **以设计稿为准**（任务书明示"与设计稿冲突处以设计稿为准并在报告说明"）——即偏离⑤。
