### 脚本面（对照 G-001 §4.1）

```ts
hud.layer(id: string, opts?: { z?: number }): HudLayer   // 幂等；owner 隔离；$ 前缀 throw
hud.layers: HudLayer[]                                   // getLayers()；本模块、z 升序、隐藏 $ 内部层
hud.removeLayer(id: string): void                        // 整层移除，元素句柄全部失效
hud.addText(id, text, x, y, color): Promise<void>        // 冻结 0.1.0；$legacy 层 upsert（color 入参 long，见偏离④）
hud.removeText(id): Promise<void>                        // 冻结 0.1.0
// hud.textIds() —— 删除（拍板⑤）

interface HudLayer {
  readonly id: string;  readonly zIndex: number;  setZIndex(z: number): void;
  readonly visible: boolean;  setVisible(v: boolean): void;
  readonly width: number;  readonly height: number;  readonly disposed: boolean;
  text(id: string, text: string, opts?: TextOptions): Draw2DElement;   // G-032（返回基类占位，G-034 收窄为 Draw2DText）
  rect(id: string, opts: RectOptions): Draw2DElement;                  // G-032（同上，收窄为 Draw2DRect）
  element(id: string): Draw2DElement | undefined;
  elements: Draw2DElement[];   // z 升序（= getElements/getElementsByZIndex）
  ids: string[];               // 与 elements 平行
  remove(id: string): void;    clear(): void;   init(): void;   // init = 无操作糖
}
```

## 关键设计决策（实施期）

1. **场景图全部收在 core**：`HudScene` 包私有（脚本不可达），`HudLayer` 是唯一脚本面；端口只收到 `addLayer(key, z, scene::paint)` 一个 Java lambda——T-200 遗留④"guest 每帧回调"结构性消除。
2. **单常驻 HudElement**：`neomacros:hud` 固定标识符，层 id 纯数据（owner 前缀、`:`、`$` 均无字符合法性问题）；z 变更只换 skiplist 键，注册表零抖动。
3. **owner 缝**：`HudApi.OwnerScope{name,onRelease}` 接口 + 生产实现 `record ModuleOwner(LoadedModule)`（record 相等性=模块 identity）+ 包私有 `ownerProbe` 构造注入——core 单测无需构造 `LoadedModule` 即可覆盖命名空间/释放/过滤三条语义；release hook 按 owner identity 去重挂接（`wiredOwners`，释放时移除 → 模块重载后重新挂接，无泄漏）。
4. **`$legacy` 一层多元素**：旧实现"每文本一层 + 每次 remove+add"的注册表抖动消失；`textIds()` 删除后其唯一消费者（compat）不存在，grep 证实。
5. **最小元素占位**：`components/Draw2DElement` 只带 `id/disposed`（任务书禁区例外，G-001 wave A 要求元素句柄才能落 `element/elements` 与生命周期断言）；`text()/rect()` 返回基类——G-034 落 `Draw2DText/Draw2DRect` 后**协变收窄返回类型**（脚本动态类型无感，Java 调用方赋给基类仍兼容）。
6. **颜色双形（拍板④）**：`number`(ARGB int) | `'#rgb'` | `'#rrggbbaa'` | 16 个原版色名（core 内自持表，零 MC 依赖）；元素 opts 走 `Map<String,Object>`（引擎 options-object→neutral map 既有通道，`CommandApi.register` 同款）。
7. **百分比坐标**：`Coord`（abs | pct）在 paint 时按 `WindowData.scaledWidth/Height` 求值——视口变化下一帧 reflow，e2e 用 640×360→1280×720 断言。
8. **`addText` color `int`→`long`**：G-030 遗留5 的既定绕法（`asLong` 全域/有符号两种写法都接受、`(int)` 截断）——修掉现役 compat 面 `hud.addText(…, 0xFFFFFFFF)` 被引擎 `Value.asInt()` 拒绝的真实 bug（本批 e2e 实测踩中）；脚本面签名/参数位/异步性不变。
9. **脚本侧句柄身份**：引擎每次跨界新建 JS 包装（`guestHandle` 无实例缓存）→ 脚本**不能**用 `===` 断言句柄身份；e2e 改用两种可观察等价物：①经第二句柄 `setZIndex` 突变、第一句柄读回（层幂等）；②同 id upsert 后旧句柄 `disposed === false`（同型保留）/ `true`（异型替换）。core 单测仍用 `assertSame`（Java 侧同宿主对象）。
10. **`dispose()` 走 `@ApiInternal`**：引擎 `handleShape` 对 `@ApiInternal` 方法整体跳过（"host-side helpers never cross to the guest"）→ 拆除面脚本不可达，同时豁免注解三件套门禁。

## 偏离清单（与 JsMacros / 任务卡 / 设计稿）

| # | 偏离 | 理由 |
| --- | --- | --- |
| ① | 在禁区 `core/api/render/components/` 新建 **`Draw2DElement.java` 最小占位**（仅 `id/disposed`） | 任务书明示"若 G-001 设计稿要求的最小占位必须建，报告写明"：G-001 §4.1/§7.1 要求 `layer.element/elements` 返回元素句柄、wave A 含元素生命周期断言；文件路径即 G-032B 任务卡落点，**G-032B 在其上扩容，不另起炉灶** |
| ② | `text()/rect()` 返回基类 `Draw2DElement` 而非 `Draw2DText/Draw2DRect` | 组件类归 G-034 族（任务书禁止）；返回类型收窄是协变演进，脚本无感 |
| ③ | `getElements()`（JsMacros 插入序快照）与 `getElementsByZIndex()`（z 序迭代器）**合并**为单一 z 升序 `elements` 属性 | G-001 §4.1 字面拍板（"= getElementsByZIndex/getElements"）；插入序仍可经 `ids` 平行面观察 |
| ④ | `addText` 第 5 参 Java 类型 `int`→`long` | 引擎 `asInt` 拒绝 >2^31（G-030 遗留5）；G-030 已立 `long` 入参先例；脚本面签名不变，冻结契约（名称/5 参/Promise）保持 |
| ⑤ | **删除 `FabricHudRegistry.java` 与 `HudApi.HudRegistry` 接口** | G-001 §5.4 构造签名直持 `RenderPort`；间接层只剩转发无职责（任务卡落点"改动"包含删除）；`textIds` 随之消失（拍板⑤） |
| ⑥ | `hud.layer(id, opts)` 用 options 对象（设计 §4.1 字面）而非 `(id, z)` 位置参 | 设计稿优先；引擎 options-object→Map 通道既有（`CommandApi.register`） |
| ⑦ | 产品侧视口 supplier **直读** `Minecraft.getWindow()`（不经 `FabricClientPort.window()`） | 后者经 `MainThread.run`（execute+2s 等待）——paint 在渲染线程内联调用有队列等待风险；直读窗口标量与"facade 不碰 MC"不冲突（supplier 由 bootstrap 注入，属 adapter 侧） |
| ⑧ | `layer.text/rect` 的 `scale/shadow/rotation` opts 目前**静默忽略** | 这些字段需要 `transform`/shadow 原语（G-001 §5.2，归 G-034）；先收不发（向前兼容），G-034 生效——见遗留 2 |
| ⑨ | `@ApiSince` 用 `0.5.0`（任务书指定），非 G-001 建议的 0.7.0 | 任务书硬规则优先；合并时若基线拍板改版号，属注解值一行级回改 |

**与任务卡/设计稿冲突的裁定**：任务卡"成员含 `getDraw2Ds/addDraw2D/removeDraw2D`"与 G-001 §4.6"P3 nested 延后"冲突 → **以设计稿为准**判 D（任务书"与设计稿冲突处以设计稿为准并在报告说明"）；同理 `width/heightSupplier`/`setOnInit/setOnFailInit` 按设计稿 A/D 判定，未按任务卡字面实现 supplier/回调。
