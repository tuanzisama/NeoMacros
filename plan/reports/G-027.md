## D 证据（本批 0 项；相关 D 口径核对）

① **NBT 族不在本 41 内，口径维持 D**：`ItemHelper.getStackWithNbt` 与 `ItemStackHelper.getNBT` 已在 15 号 §5.1 不映射表判 D（"NeoMacros 未暴露同名或等价成员"/穿透层已有等价配方），任务卡"NBT 族 D"在本批未触发——41 签名无一 NBT 成员。

② **BlockPredicateHelper 自身 4 成员 + NbtPredicateHelper 3 成员已判 D**（15 号 §5.1："NeoMacros 无对应类/模块/事件"）。本批 `getDestroyRestrictions/getPlaceRestrictions` 因此**不建** BlockPredicate 类族，落成平铺块 id 数组（状态判据/NBT 判据/test(pos) 不设）；state/NBT 判据若未来有需求按新任务另起（C 类）。

③ **13 号 §5.10 两处 "⚠ D 评估" 改判 B**：`creativeTab` 与 destroy/place restrictions 曾标 D 评估；本任务卡实施要点点名"creative tab、destroy/place restrictions"，且双端 javap 实证公有读取路径（CreativeModeTabs 族 / TOOLTIP_DISPLAY 与 CAN_BREAK/CAN_PLACE_ON 组件 + 单字段 mixin accessor），评估结论为可行 → B（回写建议见"偏离"⑧）。

## 偏离与回写

1. **命名偏离（任务卡成员名 → NeoMacros 名，Mojang 原词优先 / 13 号拍板）**：
   - `getMiningSpeedMultiplier` → `stack.getDestroySpeed`（Mojang `ItemStack.getDestroySpeed`）。
   - `canBeNested` → `stack.canFitInsideContainerItems()`（Mojang `Item.canFitInsideContainerItems`）。
   - `isSuitableFor`×4 → `stack.isCorrectToolForDrops`（13 号 §5.10 已拍板名；Mojang `ItemStack.isCorrectToolForDrops`）。
   - `areEnchantmentsHidden/areModifiersHidden` → `is*` 归一（0 参 `is*` 发布为属性，与六旗标其余四个同形）。
   - `getCreativeTab` 保留（无 Mojang 同名方法；13 号 §5.10 设计名 `creativeTab`），返回 `string[]`（扁平显示名，与 `Inventory.title` 同口径；JsMacros 为 `List<TextHelper>`）。
2. **`getBlock` 返回 `BlockState` 而非 `Block` 句柄**（交付清单外的口径说明）：NeoMacros `Block` 是位置绑定活句柄（12 号 §2.4），BlockItem 无位置；返回注册默认状态 DATA 与 G-017 D 证据①同源——不新建类型级 Block（C 超任务卡落点）。**与任务卡提示"返回 Block 句柄"不一致处以本条为准**（物理上无位置可绑定；返回类型可观察面 id/props 齐全）。
3. **restrictions 形状**：JsMacros `List<BlockPredicateHelper>` → `string[]` 平铺块 id（per-predicate 面已 D，见 D 证据②）；tag 引用展开为成员块（与 JsMacros `getBlocks` 展开一致）；组件缺席 = undefined（NeoMacros"缺席 = undefined"，JsMacros 为 `[]`——已知空列表才出 `[]`）。
4. **三态成员 `hasRecipeRemainder`**：值面 `recipeRemainder` 的"无剩余物"与"未知"同形 undefined 即可，但存在性布尔需区分 → 端口单列 `hasRecipeRemainder(itemId)`（outer empty = undefined，present = true/false）。
5. **`stackDataOf` +17 事实键（任务卡外，见下表）**：per-stack 组件（`TOOLTIP_DISPLAY` 隐藏旗标、`CAN_BREAK/CAN_PLACE_ON` 限制）只能在真实栈快照处捕获——`mcStack` 重建仅带物品默认组件，经端口懒读会全错读为 false；item 级事实（tool/wearable/fireproof/enchantability/blockId/canFit…）沿 T-420 extras 家族就地快照。键名即 G-027B 写面沿用的接口：`tool wearable fireproof blockItem blockId canFitInsideContainerItems enchantability enchantmentsHidden modifiersHidden unbreakableHidden canDestroyHidden canPlaceHidden dyeHidden hasDestroyRestrictions destroyRestrictions hasPlaceRestrictions placeRestrictions`。
6. **未知 = undefined 的新口径**：本批新事实键缺席一律 `undefined`（Boolean/Integer/List 返回可空，`asGuestValue` null→undefined），沿 G-017 extras 读面先例与本任务卡验收；**不**沿 T-420 旧事实默认值口径（`damageable→false`、`maxStackSize→1`——存量面不动）。
