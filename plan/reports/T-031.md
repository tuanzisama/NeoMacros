## 交付清单

- `ScriptEngine` SPI 扩展：`readExportedData`/`readExportedFunction`（保持 `export const meta`/`export function dispose` 契约，需求方确认）
- `GraalJsEngine`：importModule 捕获模块 namespace；导出读取（PolyglotMap loop 内深快照，禁逃逸）；guest 函数经 loop 重入执行（HostAccess.NONE 下 as(Runnable) 不可用）
- `ScriptMeta`（name/version/lifecycle/permissions 解析，未知值回退+警告）
- `EventsApi`（neo.events：on/once/off/onSync/waitFor/waitForUntil；订阅归属 tracker；异步派发到 context loop）
- `ClockApi`（neo.clock：sleep/ticks/nextTick/runOnMain；per-context AsyncPrimitives）
- `@neomacros/core` 聚合模块：`BindingRegistry.virtualSourceFor` 生成 re-export 源（子对象+平铺成员）
- `BindingRegistry.promoteRootMembers`（neo.sleep 等根级提升）+ `ModuleBinding.ofMembers`
- `ScriptApiEnvironment`（bus+adapter 静态挂点）、`LoadTracker`（loop 线程归属）、`LoadedModule`（订阅/release/dispose 回收）、`ModuleManager`（discover/load/loadPhase/unload/reloadAll）
- fabric Bootstrap：registry 注册三门面、world join/leave 相位、`/neomacros status|list|reload`、加载计数日志
- 修：`EventBus.waitFor`、`resolve.execute()` null 落定、guestMessage 防御性翻译、`asJava` 函数式接口适配（Proxy 重入）、`ContextEventLoop.isOnLoop`
