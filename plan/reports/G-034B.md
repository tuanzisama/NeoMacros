```ts
interface HudLayer {
  image(id: string, opts: ImageOptions): Draw2DImage;          // 本批新（G-032 addImage×12 的桥接目标）
  item(id: string, stack?: ItemStack | string,
       opts?: ItemOptions): Draw2DItem;                        // 本批新（G-032 addItem×24 的桥接目标）
}
type ImageOptions = { x: number|string; y: number|string;
                      w: number|string; h: number|string,
                      texture?: string; image?: Image;
                      color?: Color; region?: { x, y, w, h },
                      textureWidth?: number; textureHeight?: number,  // G-001 字面外扩展，见偏离⑧
                      scale?: number; rotation?: number;
                      zIndex?: number; visible?: boolean };
type ItemOptions  = { x?: number|string; y?: number|string,   // G-001 字面外扩展（x/y = addItem 折叠落点），见偏离⑦
                      overlay?: boolean; overlayText?: string,
                      scale?: number; rotation?: number;
                      zIndex?: number; visible?: boolean };

interface Draw2DImage extends Draw2DElement {          // 继承面见 G-032B/G-034C/G-034
  setImage(id: string, imageX: number, imageY: number,
           regionWidth: number, regionHeight: number,
           textureWidth: number, textureHeight: number): Draw2DImage;
  readonly image: string;            // getImage() 引擎折属性；未设 = undefined
  readonly imageX: number;           // … imageY / regionWidth / regionHeight
  readonly textureWidth: number;     // … textureHeight（getImageX 等 6 getter 折属性）
  setColor(color: number|string, alpha?: number, b?: number, a?: number): Draw2DImage;
  readonly color: number;  readonly alpha: number;   // getAlpha 读回 color >>> 24
}
interface Draw2DItem extends Draw2DElement {
  setItem(stack: ItemStack | string, count?: number): Draw2DItem;
  readonly item: ItemStack;          // getItem() 折属性；无堆/失效 = undefined
  setOverlay(overlay: boolean): Draw2DItem;
  shouldShowOverlay(): boolean;      // 方法（should* 不折属性，hasShadow 先例）
  setOverlayText(overlayText: string | null): Draw2DItem;
  readonly overlayText: string;
  // width/height 恒 16（盒播种）；scaledWidth = 16 × scale（JsMacros 对等）
}
// 判 D 不入面：render/setParent（G-032B 既判）、两个 Builder.createElement（upsert 承接）；
// Builder 79 签名全部折叠（拍板②，类不建）
```

## 关键设计决策（实施期）

1. **纹理消费双路 + `texture:` 优先**（G-030 交棒兑现）：`layer.image` 的 `texture`（`namespace:path`）直连既有 `DrawContext2d.sprite`；`image`（`neo.Image` PNG 快照）在 upsert 时 `ImageIO` 解码 → `RenderPort.putTexture`，id = `neomacros:image/hud/<SHA-256 前 16 字节 hex>`（内容寻址：同内容跨 re-upsert 只上传一次，每层 `uploadedSnapshots` 去重；`CustomImage` 的 `neomacros:image/<name>` 命名空间不被占用）。两路同给时 `texture` 胜（活纹理优先于快照）。上传 future 只观察不等待（无纹理面的端口保持可编译、画不出即可——`UnsupportedPortFeature` 精神）。
2. **region 采样语义 = "region>0 用 region，否则目标尺寸"**：JsMacros 2D 的采样范围由"偏移 + 目标尺寸 + 纹理尺寸"推导（region 仅 3D 生效），而 G-001 `ImageOptions.region` 是设计面——裁定为**超集**：显式 region（`setImage` 的 `regionWidth/Height > 0` 或 opts `region`）时按 region 采样（精灵图裁剪的正解），未设时逐字回退 JsMacros 规则（源范围 = 目标尺寸）。13 参 `blit` 的 region 槽位天然承载两者。
3. **`DrawContext2d` 两个 default 新面零破坏**：12 参 `sprite` default 委托 5 参裸精灵（旧适配器行为不变）、`item` default 空实现（先于物品面的屏幕上下文/桩只需可编译）；5 个既有实现（2×ScriptScreen、FakeScreenPort、e2e screen sink、RecordingHudRender）不被强制覆写，仅 HUD 路径的两个记录器 + Fabric 覆写。
4. **物品渲染走 item stack 精灵，装饰独立开关**：`extractor.item(mcStack, x, y)` 画 16×16 图标；装饰（耐久条/冷却/数量或标签）由 `extractor.itemDecorations(font, stack, x, y, overlayText)` 承载——vanilla 4 参形 bytecode 实证即 5 参传 `null`（两节点同式），故 primitive 一个 5 参形全覆盖 `overlay=false`（不调）、`overlay=true + label=null`（数量）、`overlay=true + label=串`（自定义标签）。堆中立重建复用 `FabricInventoryPort.mcStack`（同包，potion extras 已带）。
5. **`setItem` 纯 core 解析**：`ItemStack` → `toData()`；物品 id → `ItemStackBuilder(id).count(n).build().toData()`（纯数据构建，零端口依赖——core/e2e 桩环境零安装即可测）；绘制期才经 `mcStack` 解析注册表，未知 id → 空气堆不画（JsMacros"未知 id 解析为默认物品（空气）"的可观察行为同式，偏离⑥）。
6. **句柄身份与 fluent**：`HudScene.upsert` 按 Kind 工厂构造子类句柄（同型保句柄、异型替换失效语义不变）；`image/item` 协变收窄返回子类；组件 mutator 自持 `requireAlive()` + `publish` 双保险（G-034C 契约）；`setPos(4)/Item 双 setItem` 等同名重载全部折叠（铁律①）。
7. **嵌套句柄穿越 opts 的引擎根修**：`image: <CustomImage 快照>` 是本仓第一个"句柄嵌在 options 对象里"的面——`GraalJsEngine.asNeutral` 原只探一层 `__neoCell`（裸代理够用），guest 类实例的句柄在 `__cell` 下的成员代理里（第二层），旧路径会把 `Image` 枚举成属性 Map。裁定：`asNeutral` 首分支改走既有的 `hostCellOf`（与 `asJava` 注释同款的双层探针），**顶层参数路径行为逐位不变**（`convertArgument` 本来就先探），嵌套路径从"属性 Map"修正为宿主活句柄——对既有 API 零可观测破坏（此前没有任何 API 的 opts 收嵌套句柄），对 `Payloads.snapshot` 直通返回值无影响（unknown 对象原样返回）。见偏离⑭。
8. **颜色面与 alpha 语义逐字对齐 G-034**：`setColor` 折叠四元分派 + 5 个 `@ApiInternal` 宿主重载；`getAlpha = color >>> 24`；不复刻"零 alpha 非零 RGB → 不透明"怪癖（G-034 偏离⑦ 同口径）。`Draw2DItem` 无颜色面（JsMacros 物品不被元素色 tint）。

## 偏离清单（与 JsMacros / 任务卡 / 设计稿）

| # | 偏离 | 理由 |
| --- | --- | --- |
| ① | `Image.setPos(4 参)` 无同名成员 → 折叠 `setPos(x,y)+setSize(w,h)` 链 | 与基类 `setPos(2 参)` 同名重载按 G-033 铁律①只留一个；能力 100% 承接（两目标均为既有基类面，故记 A）；审计需 `setPos` arity 注 |

| ③ | `getImage()` 未设纹理时返回 `undefined`；JsMacros 抛 `NullPointerException` | 失效语义统一表（读 undefined）优先于复刻 NPE；脚本可用 `img.image === undefined` 判未设 |
