## 命名与形态决策

1. **`command.names` 是属性不是方法**：13 号 §1 规则 1（无参状态查询属性化，先例 `input.pressedKeys`）；语义 = 连接派发器根节点子名快照（服务端 + 客户端，含 JsMacros `getValidCommands` 同款范围），会话前为空数组。
2. **`command.suggestions(part)` 而非 `getArgumentAutocompleteOptions`**：异步 Promise（12 号「异步一律 Promise」）；名词作查询函数沿 `registry.ids(kind)` 先例；JsMacros 词缀不沿用（13 号 §1 规则 5）。
3. **类名 `SuggestionsBuilder`**：Mojang/brigadier 官方词优先，弃 `SuggestionsBuilderHelper`（15 号 §1.3 不沿用 Helper 命名）；`@ApiClass(kind=HANDLE)` 中立句柄（不 wrap 游戏对象，同 `CommandContext`），实现 `ScriptHandle` 以走 `guestHandle` 宿主类渲染。
4. **`suggests` 挂在 `CommandArg` 上、形态 = 数组或回调二选一**：G-026 报告遗留 2 的第一方案；`optional()/defaultTo()/range()` 同族链式不可变成员。JS 函数跨界经既有 `asNeutral → Consumer<Object[]>` 通道（G-026 修的就是这条通道），数组经 `ArrayList`，零引擎改动。
5. **一个 greedy 尾节点服务全命令**：brigadier 侧唯一必需的结构变化。literal 与尾节点**都**挂同一 handler（brigadier 规则：最深节点必须自带 `executes`，实测确认），尾节点同时承载 `suggests`。结构对所有命令统一（spec 热替换不产生陈旧树），handler/补全均按名活查。
6. **`suggest(int)` 的数字渲染**：整数值去小数尾（`3.0 → "3"`），其余按 `Double.toString`——JsMacros `String.valueOf(int)` 的中立化对应物。
7. **回调路由在 core（`CommandArg.suggestAt`），回放在 adapter**：core 拿 `input/tailStart` 自算当前 token（与 JsMacros 的「节点起点 = 当前 token」语义对齐），适配器只做 `createOffset + suggest + add`，宿主单测与脚本看到同一形态。

## 与 JsMacros 的语义差异（有据）

1. **坐标建议的匹配粒度**：JsMacros 走 `SharedSuggestionProvider.suggestCoordinates`（按分量逐段匹配、按分量段替换）；NeoMacros 的 `pos()` 槽是单 token 原文（G-026 拍板），故 `suggestPositions/suggestBlockPositions` = 整串候选 + 整 token 前缀过滤（校验规则与 JsMacros 逐字一致：2/3 分量、整批一致）。分量级匹配在扁平单 token 模型下无观察面，不复刻。
2. **`suggestIdentifier` 对非法条目**：JsMacros `ResourceLocation.parse` 抛错使整批失败；NeoMacros 跳过非法条目（坏数据只损失它自己，不拖垮该命令的全部补全）。
3. **注销后的残余**：JsMacros 用反射从派发器子表里真删节点；NeoMacros 按 15 号 §8「不为一个成员引入大范围 mixin/脆弱 accessor」不反射——执行被 `requires` 门禁掉、`command.names` 被 retired 集合滤掉、槽位补全被活查滤掉，**唯一残余**是根级命令名建议在重新进服前仍会出现该名（见遗留 1）。
4. **多余尾 token**：JsMacros 由 brigadier 报 `Unknown argument`；NeoMacros 现由扁平解析器报 `unexpected input '<tok>'`（见下方行为变化第 2 条），`greedy` 槽照旧吞掉整行不报。
5. **`suggestWithTooltip` 的 tooltip 类型**：JsMacros `TextHelper` → NeoMacros `TextComponent`（`new neo.Component(...).build()`），中立模型。
6. **折叠成员**：`suggest(int/String)`、`suggestMatching(String.../Collection)` 等 Java 同名重载在脚本面各折叠为一个成员（JavaInterop 按名分发），compat 回桥需把 varargs 包成数组。
