# T-033 storage 模块

- 状态: done
- 分支: t033-storage
- 日期: 2026-10-31

## 交付清单

- `ModuleStorage`：每脚本 JSON KV（get/put/delete/has、防抖落盘、close 强制 flush、损坏回退空启、文件名 sanitize）
- `StorageApi`（neo.storage + @neomacros/storage）：per-script 隔离，key 用**源文件 stem**（meta 解析前即稳定，避免 store 文件分裂）
- `ScriptApiEnvironment`：storageDir 装配 + 按名缓存 + closeStorages（flush 钩子接 game:quit）
- 引擎配套：`asJava` 的 `Object` 参数中立快照（asNeutral：标量直转/对象成员枚举/数组枚举，绕开 HostAccess.NONE 下的 as(Map/Runnable) 限制）、`guestView`（返回值快照 + ProxyObject/ProxyArray 包装，保证 guest 在 HostAccess.NONE 下可读）
- fabric Bootstrap：StorageApi 注册、storage 目录装配、quit 时 flush

## 验证结果
