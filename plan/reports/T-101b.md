## 关键发现

1. **26.3 LivingEntity.hurt 被拆分为 hurtServer**（服务端方法）：客户端 mixin 注入 hurt 会找不到方法。需要研究客户端伤害追踪的正确方式（per-tick 健康快照差量或专用 mixin）
2. **26.3 Fabric keybinding API 包路径变更**：`keymapping/v1`（非 `keybinding/v1`），方法 `registerKeyMapping(KeyMapping)`
3. **26.3 KeyMapping.Category 是 record**：`Category.register(Identifier)` 自注册分类
